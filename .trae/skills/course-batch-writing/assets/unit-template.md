2. {{阶段目录绝对路径}}/{{编号2}}-{{标题2}}.md

每个文件严格采用六段式结构（## 二级标题，顺序固定）：
目标 / 技术栈 / 详细的理论知识讲解和示例伪代码 / 课后题 / 实践练习题 / 阶段验收作业。

硬性要求：

- 单篇 ≥600 行（写完用 `wc -l` 自查），无注水、无占位符（禁止“略/TODO/待补充”）。
- 文件首行 `# 标题` 与文件名一致。
- 目标：8-10 条行为化能力点。
- 技术栈：表格列出工具/API、用途、学习要求。
- 理论：10-15 个 `###` 小节，每节讲清“是什么 / 与{{领域}}开发的关系 / 可运行示例 / 常见误区”；代码用真实语法置于代码块，禁止 HTML 标签与 DOM 假设。
- 课后题：恰好 10 道，含场景分析题。
- 实践练习题：恰好 3 个，每个含 任务 / 概念伪代码或参考代码 / 步骤约束 / 提交物 / 验收标准。
- 阶段验收作业：任务描述 / 完成标准 / 100 分评分表 / 强制不通过条件。
- 术语红线：{{如：逻辑层无 window/document；setData 跨线程异步；密钥不放前端}}。
- 不修改任何其他文件，不更新 README 或链接。
