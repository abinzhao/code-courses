# 02 浏览器、DOM 与 JavaScript

## 阶段任务

在不依赖框架的前提下理解浏览器进程、渲染管线、DOM、事件、Storage、Fetch、Worker 和观察器 API，并完成可交互的原生页面。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W13–W14 | 页面生命周期、DOM、CSSOM、事件和表单事件 | 原生文章列表 |
| W15–W16 | Web API、请求、存储、Worker 和观察器 | 搜索、上传模拟和阅读清单 |

## 阶段成果

- 能从浏览器面板追踪一次交互和一次请求。
- 使用事件委托和模块边界完成原生阅读清单。
- 使用 `AbortController`、`FormData` 和观察器 API。
- 能解释同源策略、缓存、XSS、CSRF 和事件循环的基本关系。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第三阶段浏览器dom-与-web-api)。
