# 01 SFC、模板与商品组件

> 本章目标：从 Vue 单文件组件的编译边界出发，建立类型完整、身份稳定、可由 Vite 构建的邻里集市静态商品页。

## 本章任务

你将把两条静态 `Listing` 数据渲染为语义清楚的商品卡片。页面只展示教学种子，
不访问网络、不建立会话，也不产生真实预约。完成后应能解释浏览器为什么不能直接执行
`.vue` 文件、父子组件如何分工，以及列表重排时为什么必须使用稳定业务 ID。

## 前置与产出

- 前置：HTML 语义、CSS 基础、TypeScript 对象与联合类型、ES module。
- 输入：`lamp-1` 与 `desk-1` 两条静态商品数据。
- 输出：一个 Vue 3.5 SFC 应用、两张卡片、类型检查和生产构建证据。
- 建议投入：4.5 至 6 小时；每课 90 至 120 分钟。
- 明确边界：静态数据和浏览器内存不是持久化；组件隐藏按钮不是授权。

## 章级邻里集市任务

在个人练习目录创建 `neighborhood-market/apps/vue-web`，渲染以下固定数据：

- `lamp-1`：九成新台灯，`3500` 分，`available`，`seller-1`；
- `desk-1`：折叠桌，`8000` 分，`reserved`，`seller-2`；
- `createdAt` 保存为带 `Z` 的 UTC ISO 8601，显示时才本地化；
- 卡片主体由子组件负责，编号或后续操作由父组件通过插槽提供。

重排两条商品后，商品标题、输入焦点和组件局部身份不得迁移到另一条商品。将卖家描述改为
`<img src=x onerror=alert(1)>` 时，页面应显示文字而不是执行 HTML。

## 综合验收

- [ ] `pnpm typecheck` 和 `pnpm build` 均退出 `0`。
- [ ] 浏览器显示 35 元台灯与 80 元折叠桌，价格源值仍是整数分。
- [ ] `createdAt` 保持 UTC 字符串，只有展示函数进行本地化。
- [ ] 320 CSS 像素宽度下无页面级横向溢出，Tab 焦点清晰。
- [ ] 把 `:listing` 错写成静态 `listing` 后，`vue-tsc` 能给出失败证据。
- [ ] 使用稳定 `item.id` 作为 key，重排后卡片身份不串位。
- [ ] 页面明确写出“静态教学数据，不创建真实预约”。

完成证据包括命令原始输出、浏览器截图或检查记录，以及一次按“现象、证据、原因、修复、
复验”整理的错误记录。只看到开发服务器页面不等于类型检查和生产构建已经通过。

## 能力边界

本章不处理响应式写入、表单、HTTP、路由、认证或后端授权。下一章才把静态列表变成
可搜索、可发布但仍仅存在于浏览器内存中的教学应用。
