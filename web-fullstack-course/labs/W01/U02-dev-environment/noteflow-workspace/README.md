# NoteFlow 学习工作区

这是 W1 Git 实验的起始文件。请先把整个目录复制到 `/tmp/noteflow-w1-workspace` 或其他你明确知道的临时目录，再在复制品中执行 `git init`。

## 目录约定

```text
noteflow-workspace/
├── README.md
└── 后续单元会逐步增加的实验目录
```

## 当前运行方式

W1 只验证目录、环境和 Git 历史。下一步教程会把浏览器实验和项目文件逐步放入这个工作区。

## 首次提交建议

```bash
git init
git add README.md
git commit -m "docs: initialize NoteFlow learning workspace"
git log --oneline -1
```

提交中不要包含真实密钥、访问令牌、密码、生产数据或个人隐私文件。
