# 05 DOM、事件与可访问状态

## 本章任务与产出

本章把普通 JavaScript 状态转成安全、可操作的浏览器界面。你将先建立状态到 DOM 的单向渲染，再掌握表单提交和事件委托，最后完成支持键盘、状态播报和焦点恢复的邻里集市内存商品页。

完成后你将得到：

- 一个可见比较 `textContent` 与错误 `innerHTML` 的安全渲染实验；
- 一个覆盖捕获、冒泡、表单和一次事件委托的独立事件实验；
- 一套完整的 `index.html`、`app.mjs` 与 `server.mjs` 内存应用；
- 一份 Chromium 键盘路径、焦点位置和 Console 证据。

运行条件：Node.js 24 LTS 只启动静态服务，DOM 逻辑在现代浏览器执行。

## 必要前置

先完成：

- [对象、数组与数据边界](./03-objects-arrays-data.md)
- [原型、类与 ECMAScript 模块](./04-prototypes-modules.md)
- HTML 卷的语义、表单和可访问名称课程

本章不接入账户、数据库或真实写 API。所有商品、收藏与筛选状态都只存在于当前页面内存；刷新恢复初始数据。页面按钮不证明身份，也不授予服务端对象权限。

## 章级邻里集市任务

在 `js-lab/dom-market/` 完成内存商品页：

1. 首次显示两个初始商品，其中允许 0 分价格；
2. 表单严格把元文本转为非负安全整数分；
3. 标题和消息全部作为文本写入，不拼接外部 HTML；
4. 列表只注册一个委托监听器；
5. 收藏由 `Set` 保存稳定 ID，筛选由源状态派生；
6. 收藏和筛选按钮同步可见文字与 `aria-pressed`；
7. 重渲染、取消收藏和删除后恢复合理焦点；
8. 状态区域报告成功与失败；
9. 页面持续显示“教学内存模式，刷新复位”；
10. “从内存移除”不冒充服务器删除或权限判断。

## 综合验收证据

- [ ] 安全区域把带标签标题显示为纯文本，DOM 中无注入后代；
- [ ] HTML 约束失败和程序金额失败都不会新增商品；
- [ ] 点击提交与 Enter 提交行为一致，一次操作只更新一次状态；
- [ ] 初始渲染、合法发布、非法发布、收藏、收藏移除和筛选恢复均通过；
- [ ] 操作全程可用 Tab、Shift+Tab、Enter 与 Space 完成；
- [ ] 删除后聚焦相邻商品或当前筛选按钮，没有焦点落到 `<body>`；
- [ ] 刷新后新增和收藏消失，恢复两个源码初始商品；
- [ ] Console 零未处理错误，静态资源请求零 404。

保存关键步骤截图或 DOM/Console 记录；不要把未执行的 Safari、Firefox 或屏幕阅读器检查写成通过。
