# 06 异步、Fetch 与事件循环

## 本章任务与产出

本章从 Promise 调度模型进入 Fetch 协议边界，再完成可取消且不会被旧结果覆盖的邻里集市搜索控制器。

完成后你将得到：

- 一份可预测同步栈、微任务和计时器顺序的事件循环实验；
- 一个覆盖成功及多层失败、自行关闭的本地 Node 教学 API；
- 一套结合 `AbortController`、代次守卫、防抖清理和释放语义的搜索控制器；
- 一组不用时间睡眠、可确定性复现旧成功和旧失败的竞态证据。

运行基线为 Node.js 24 LTS。浏览器与 Node 的公共 Promise 语义可以复用，渲染时机与 Node 特有事件循环阶段必须分别验证。

## 章级邻里集市任务

完成一个“连续搜索两次，只展示最新有效分页”的控制器：

1. 使用 `URLSearchParams` 构造查询；
2. 将网络失败、HTTP 非 2xx、JSON 解析失败、运行时契约失败分别建模；
3. 401 进入重新认证状态，409 进入冲突恢复，500 保留 `requestId`；
4. 商品页只有通过已知字段重建后才能进入 UI；
5. 每次搜索创建独立 `AbortController`，新搜索取消旧信号；
6. 成功和失败都检查请求代次；
7. `dispose()` 清理活动请求与防抖计时器，并阻止后续渲染；
8. 通过可控 Promise 让旧请求在新请求之后成功和失败；
9. 明确客户端取消不保证服务端事务回滚。

## 综合验收证据

- [ ] 事件循环输出在执行前预测正确，并能标注同步、微任务和计时器；
- [ ] 本地 API 验证 200、400、401、404、409、500；
- [ ] 成功状态非法 JSON 分类为解析失败，合法 JSON 非法字段分类为契约失败；
- [ ] 服务关闭后的请求分类为网络失败，本地进程自行退出；
- [ ] 连续搜索中只有新查询产生 success；
- [ ] 旧成功、旧失败、当前失败、显式取消和释放后完成分别可观察；
- [ ] 竞态验证不用随机延迟或睡眠；
- [ ] Cookie、CORS、CSRF、认证、对象授权和事务取消边界表述准确。

保存命令输出和状态序列。Safari、Firefox、真实弱网、代理中断和生产身份系统未实际验证时必须列为缺口。
