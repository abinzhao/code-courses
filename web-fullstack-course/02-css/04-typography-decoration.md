# 04 字体、文本与视觉装饰：在美观之前保证可读

## 本章任务

为邻里集市建立可回退的字体、可国际化的文本和不承载唯一信息的视觉装饰。完成后，你能解释字体加载如何改变字形度量、文本为何溢出，以及背景、阴影、滤镜和裁剪如何影响合成与可访问性。

## 产出与前置

- 产出：3 个最小观察台、3 个邻里集市完整页面、字体回退记录、文本边界清单和装饰降级证据。
- 前置：完成盒模型、溢出、颜色与对比度单元。
- 边界：本章不把第三方字体文件加入仓库，也不声称完成真实屏幕阅读器或所有语言排版验证。

## 学习路线

1. [字体加载、回退与度量](./04-typography-decoration/01-font-loading-fallback-metrics.md)
   从 family 匹配到 font face 加载，控制回退度量与布局偏移。建议 120 分钟。
2. [换行、国际化与可读性](./04-typography-decoration/02-line-breaking-i18n-readability.md)
   处理行盒、间距、断词、溢出、双向文本和竖排边界。建议 150 分钟。
3. [背景、边框、阴影、滤镜与裁剪](./04-typography-decoration/03-background-border-shadow-filter-clip.md)
   构建分层装饰并验证对比、焦点、裁剪和降级。建议 120 分钟。

学习顺序不可颠倒：字体度量影响行盒与换行，文本布局稳定后才能安全叠加装饰。

## 邻里集市综合任务

- 使用系统字体栈作为可靠基线，可选 Web Font 失败时页面仍可阅读；
- 字体切换有布局偏移观察，不用隐藏文本长期等待字体；
- 长商品名、URL、混合语言和放大文本均能合理换行；
- 行高、行宽、字间距不以固定高度裁切；
- 背景与装饰不承载价格、状态或错误等唯一信息；
- 阴影、滤镜、clip 和 mask 失效时，边界与焦点仍可辨认。

## 综合验收

- [ ] 能区分字体 family 匹配、face 选择、加载与度量回退。
- [ ] 无网络或字体失败时页面保持可读、无永久不可见文本。
- [ ] 320px、200% 缩放、长 URL 和中英混排下无关键信息裁切。
- [ ] 能说明 `overflow-wrap`、`word-break`、`white-space` 和 `hyphens` 的职责差异。
- [ ] 关闭背景图、阴影、滤镜和裁剪后，结构与状态仍可理解。
- [ ] 官方来源、兼容边界与未进行的人工验证均明确记录。
