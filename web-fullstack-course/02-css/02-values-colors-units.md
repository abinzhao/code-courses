# 02 值、颜色与单位：把设计要求变成可计算结果

## 本章任务

为邻里集市建立可缩放的尺寸与颜色系统。你要能写出每个相对值的参照物，追踪它从指定值到实际绘制值的阶段，并在新颜色或单位不可用时保留可读回退。

## 产出与前置

- 产出：3 个最小观察台、3 个邻里集市完整页面、值阶段记录、尺寸推导和对比度证据。
- 前置：完成第 1 章，能用 Styles 与 Computed 面板定位胜出声明。
- 边界：CSS 中显示的 `39.00 元` 不改变项目“价格存储与传输使用整数分”的契约；视觉对比检查不能替代真实辅助技术测试。

## 学习路线

1. [值阶段、单位与百分比](./02-values-colors-units/01-value-stages-units-percentages.md)
   区分指定、计算、使用和实际值，写清绝对/相对长度与百分比参照。建议 120 分钟。
2. [字体、视口、容器单位与数学函数](./02-values-colors-units/02-font-viewport-container-math.md)
   在缩放、移动视口和组件容器中建立有上下界的响应尺寸。建议 120 分钟。
3. [颜色空间、透明度与对比度](./02-values-colors-units/03-color-spaces-transparency-contrast.md)
   组合 sRGB、HSL、现代颜色、alpha、系统颜色和明确回退。建议 120 分钟。

第 2 篇依赖第 1 篇的参照物分析；第 3 篇沿用同样的值阶段检查，并加入视觉与兼容边界。

## 邻里集市综合任务

构建商品摘要区域：

- 文本与间距响应用户根字号，页面在 200% 缩放后不丢内容；
- 卡片宽度由包含块决定，内部模块可按容器而非整个视口调整；
- 流式字号和间距有可解释的最小值、首选项、最大值；
- 品牌色先给 sRGB 回退，再渐进启用现代颜色；
- 透明层叠后仍检查最终背景上的文字对比，不用 opacity 淡化整个可交互组件；
- 页面标注静态数据，不把 CSS 格式化描述成金额计算。

## 综合验收

- [ ] 能为一个属性写出 specified、computed、used、actual 四阶段证据。
- [ ] 每个百分比、相对单位和数学表达式都能指出参照物与失效条件。
- [ ] 320px 宽度、200% 缩放和长文本下无关键内容裁切。
- [ ] 容器查询不支持时仍有可读的基础布局。
- [ ] 新颜色语法有前置 sRGB 回退，最终前景/背景组合有对比度记录。
- [ ] 三次故障注入均包含现象、证据、原因、修复和复验。
