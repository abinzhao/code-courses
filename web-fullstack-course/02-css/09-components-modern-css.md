# 第九章：现代 CSS 组件与系统环境

> 用可继承的主题契约、可解释的层叠边界和原生控件能力构建组件。

## 本章任务

为邻里集市制作一个商品发布预览组件。它能切换主题、校验本地输入、嵌入不同页面，并在窄屏、打印、强制颜色与减少动作环境中保留完整内容和操作边界。

## 学习成果

完成本章后，你能够：

- 推导自定义属性在指定值、计算值和继承阶段的替换结果；
- 设计语义主题 token，并处理无效值、回退和循环引用；
- 使用 `@property` 注册类型、继承行为和初始值；
- 用 `@layer` 建立可审计的来源顺序和特异性预算；
- 正确使用原生嵌套，不套用 Sass 字符串拼接模型；
- 用 `@scope` 限定匹配范围并提供旧环境回退；
- 保留原生表单语义、键盘、焦点、错误文字和高对比能力；
- 设计滚动、打印与强制颜色路径；
- 区分 CSS 呈现状态、浏览器约束验证与服务端业务验证。

## 章级综合任务

在个人目录创建 `practice/css-09-publish/index.html`：

1. 用 `--surface`、`--text`、`--border`、`--accent` 建立语义主题契约；
2. 默认主题响应系统偏好，用户按钮可在当前页面显式覆盖；
3. 一个注册的装饰变量可插值，缺少 `@property` 时仍有静态回退；
4. 样式按 reset、base、components、utilities、overrides 声明层顺序；
5. 必要样式提供普通选择器主线，嵌套和 `@scope` 只在兼容边界内使用；
6. 标题与整数分价格有持久 label、文字错误和提交时机；
7. 原生控件保留键盘、焦点和强制颜色映射；
8. 结果区可滚动定位，reduce 模式关闭平滑滚动；
9. 打印版移除操作控件，保留商品、价格和“未发送请求”说明。

## 综合故障演练

- 让颜色 token 取得长度值，记录计算值阶段的无效声明；
- 制造自定义属性循环，比较有无 `var()` 回退；
- 把未分层规则与分层规则混用，观察优先级；
- 在嵌套父列表加入 ID，记录特异性预算变化；
- 移除 `@scope` 支持，确认基础组件仍可用；
- 对所有控件使用 `appearance: none`，复现状态不可辨；
- 初始就显示 `:invalid` 红框，记录验证时机问题；
- 打印保留 fixed 操作栏，复现遮挡后修复。

## 本章验收

- [ ] 主题 token 名称表达语义而不是具体色值；
- [ ] 无效替换、继承、回退和循环均有可复现说明；
- [ ] `@property` 缺失时必要内容仍可读；
- [ ] 层顺序和 important 反转规则可解释；
- [ ] 嵌套与作用域没有抬高不可控特异性；
- [ ] 无样式或系统重映射下表单仍有标签和错误文字；
- [ ] 键盘、窄屏、reduce、打印与强制颜色路径可用；
- [ ] CSS 校验没有被描述成授权、持久化或服务端验证；
- [ ] 已记录 Safari、Firefox、打印引擎和辅助技术的未验证范围。
