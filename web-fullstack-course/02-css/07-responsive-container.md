# 第七章：响应式布局与容器查询

> 不猜设备型号，按内容空间、组件容器、输入能力和用户偏好调整邻里集市。

## 本章任务

让同一张商品卡既能进入全宽目录，也能进入窄侧栏；页面在小屏、宽屏、打印、RTL、粗指针、减少动作和强制颜色下都有可用路径。

## 学习成果

完成本章后，你能够：

- 从内容开始拥挤的位置选择移动优先断点；
- 区分媒体查询的视口/能力条件与容器查询的嵌入空间条件；
- 解释 `container-type` 的包含副作用和容器单位回退；
- 使用逻辑属性支持 LTR、RTL 与书写模式；
- 区分 `hover`、`pointer` 与 `any-pointer`，不把触屏当设备身份；
- 处理安全区、动态视口、打印、减少动作、对比和强制颜色；
- 建立 320px、200% 缩放、长内容、键盘与打印预览的证据矩阵。

## 章级综合任务

在个人目录创建 `practice/css-07-market/index.html`：

1. 页面小空间默认单列，内容需要时在 48rem 以上增加筛选侧栏；
2. 同一商品卡分别放入窄侧栏和宽目录，布局由命名容器决定；
3. 标题字号用有上下限的容器单位表达，不允许无限缩放；
4. 间距和角标使用逻辑属性，切换 `dir="rtl"` 后仍合理；
5. 悬停只做增强，键盘焦点始终可见，粗指针点击目标足够；
6. 安全区使用 `env()` 并保留 `0px` 回退；
7. 减少动作、强制颜色和打印规则不隐藏价格、状态与恢复说明；
8. 页面明确标注商品与收藏为静态/内存演示。

## 综合故障演练

- 删除 viewport 声明，记录移动模拟下的布局视口差异；
- 用设备名称或方向替代内容断点，制造窄桌面失败；
- 删除查询容器，证明 `cqi` 有值也不能证明参照正确；
- 对查询容器自身按自身尺寸改宽度，记录循环限制；
- 同时混用 `left` 与 `inset-inline-start`，在 RTL 中观察冲突；
- 只在 `hover` 显示操作，使用键盘和触摸模拟证明不可达；
- 在打印预览中保留 fixed 工具条，记录遮挡并修复。

## 本章验收

- [ ] 320px、768px、1280px 与 200% 缩放无必要内容丢失；
- [ ] 断点有内容拥挤证据，不引用手机型号；
- [ ] 同一视口内宽、窄容器能呈现不同卡片布局；
- [ ] 能解释 `inline-size` 查询包含及其尺寸副作用；
- [ ] LTR、RTL、键盘、粗指针和无悬停路径可用；
- [ ] 减少动作、强制颜色与打印预览保留核心信息；
- [ ] 长标题、五位价格、空状态与错误状态不溢出；
- [ ] 已记录 Safari、Firefox、真实移动设备和辅助技术的未验证范围。
