# 第十章：CSS 属性、语法与兼容参考

> 参考不是名称堆积，而是值、上下文、证据和回退组成的可审计工具。

## 本章任务

把前九章使用的 CSS 能力整理为三层参考：476 项固定属性与模块索引、at-rule/描述符/函数分类、有限与实验能力回退登记。学习者最终能从问题定位机制，并证明增强缺失时核心任务仍成立。

## 学习成果

完成本章后，你能够：

- 按模块检索属性的值、行为、简写和适用上下文；
- 机械复核 476 项属性名称、顺序、唯一性与哈希；
- 区分普通属性、描述符、at-rule、值函数和函数式选择器；
- 判断函数产出类型能否进入当前属性语法；
- 区分规范状态、兼容数据、当前解析与真实行为证据；
- 分类有限支持、实验、弃用、非标准和已移除能力；
- 为新能力编写基础路径、检测、回滚、升级和删除条件；
- 避免把 CSS 呈现能力误写成业务验证、授权或持久化。

## 章级综合任务

在个人目录创建 `practice/css-10-audit/`：

1. 从第一课审计区机械提取 476 个首列名称；
2. 验证顺序数 476、唯一数 476、SHA-256 与课程基线一致；
3. 为布局、文字、绘制、动画、交互、打印与 SVG 各选一项属性，记录值与上下文；
4. 从第二课各选一个 at-rule、描述符、值函数和函数式选择器，解释分类；
5. 故意把描述符和函数放错上下文，保留 Styles/Computed 失败证据；
6. 从第三课选择一项有限支持能力，填写完整回退登记；
7. 在禁用增强、reduce、键盘、320px、200% 缩放和打印下复验；
8. 将结果与 [CSS 覆盖矩阵](CSS-COVERAGE.md) 的对应 ID 对账。

## 476 属性审计契约

- **审计文件：**`10-property-reference/01-stable-properties-module-index.md`；
- **提取边界：**`PROPERTY-AUDIT-START` 到 `PROPERTY-AUDIT-END`；
- **提取口径：**Markdown 表格首列反引号名称；
- **顺序项：**476；
- **唯一项：**476；
- **SHA-256：**`e38b0f5d2a6a12e1cf772cb89010279737f2b3814bb57732e4fa0f1139486734`；
- **变更规则：**任何名称增删、改名或重排必须单独评审并同步覆盖矩阵。

at-rule、描述符、函数、选择器、伪元素和 JavaScript API 不混入这一数量。

## 综合故障演练

- 给 padding 写负值，记录无效声明的错误恢复；
- 用 background 简写覆盖先前图层，定位重置来源；
- 把 `font-display` 写进普通元素，证明描述符上下文错误；
- 把 gradient 写进 color，证明函数产出类型不符；
- 只凭 `CSS.supports()` 声称全平台支持，再用行为矩阵纠正；
- 删除实验能力的基础路径，复现核心内容不可达；
- 用 UA 品牌开关帮助内容，模拟字符串与能力不一致；
- 修改一项属性名称，证明 count/hash 门禁能阻止静默口径漂移。
