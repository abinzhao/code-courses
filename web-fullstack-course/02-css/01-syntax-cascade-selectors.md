# 01 CSS 语法、层叠与选择器：解释样式为什么生效

## 本章任务

为邻里集市建立第一套可解释的样式规则。完成后，你不只会让价格变色，还能从解析、层叠和选择器匹配三个层面说明浏览器为何采用某个值。

## 产出与前置

- 产出：3 个可独立运行的 HTML 页面、3 份诊断记录和一份层叠决策表。
- 前置：会创建 HTML 文件，能在浏览器中打开 Elements、Styles、Computed 和 Network 面板。
- 边界：本章只讨论作者 CSS 的基础机制；布局从第 3 章开始，动画层叠位置在第 8 章展开。

## 学习路线

1. [规则、解析与接入位置](./01-syntax-cascade-selectors/01-rules-parsing-entry-points.md)
   从 token、规则和声明开始，观察非法声明、计算值阶段失效以及外部样式表加载证据。建议 90 分钟。
2. [层叠层、特异性与确定性决策](./01-syntax-cascade-selectors/02-cascade-layers-specificity.md)
   按来源与重要性、层、特异性、作用域接近程度、源码顺序建立固定判断流程。建议 120 分钟。
3. [选择器、伪类与继承](./01-syntax-cascade-selectors/03-selectors-pseudo-classes-inheritance.md)
   用关系选择器和状态伪类表达商品状态，并区分直接声明与继承值。建议 120 分钟。

必须按顺序学习：第 2 篇依赖第 1 篇的“声明是否进入候选集”，第 3 篇依赖第 2 篇的“匹配后如何决胜”。

## 邻里集市综合任务

创建一个含“可预约”和“已售”商品的静态列表：

- 外部样式表成功加载，并能在 Network 中找到 200 响应与 `text/css` 类型；
- 用层明确组织基础、组件和工具规则，不用 `!important` 解决普通组件冲突；
- 用属性选择器表达商品状态，用 `:focus-visible` 保留键盘焦点；
- 价格最终颜色可在 Computed 中复述完整决策链；
- 删除样式表、写错属性值、改变 DOM 关系后，分别留下诊断证据。

## 综合验收

- [ ] 三篇教程中的完整页面均可从本地直接打开并观察预期结果。
- [ ] 能区分“规则未匹配”“声明解析失败”“计算值阶段失效”“候选声明被覆盖”。
- [ ] 能按固定顺序判断同一属性的胜出声明，而不是只说“后写覆盖前写”。
- [ ] 能写出类型、类、属性、关系、函数伪类和伪元素选择器，并说明各自匹配范围。
- [ ] 能解释子元素直接声明为何可替代从高特异性父元素继承的值。
- [ ] 每个故障都有现象、证据、原因、修复和复验记录。
