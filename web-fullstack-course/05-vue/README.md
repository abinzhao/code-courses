# 05 Vue 3

## 阶段任务

使用 Vue 3 Composition API、SFC、Pinia 和 Vue Router 实现与 React 版相同的 NoteFlow 团队后台，再通过可运行代码比较两套框架的响应式和组件通信模型。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W27–W29 | 模板、响应式、组件、slots、composable 和表单 | Vue 文章列表与编辑器 |
| W30–W32 | Router、Pinia、VueUse、测试、性能和 Nuxt SSR | Vue 团队管理后台 |

## 阶段成果

- 能解释 `ref`、`reactive`、`computed`、`watch` 和依赖追踪。
- 能设计 Props/Emits、slots、provide/inject 和 composable 边界。
- 完成 Pinia 状态、路由守卫、组件测试和错误状态。
- 能解释 React 与 Vue 在渲染、组合复用和调试上的差异。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第六阶段vue-3)。
