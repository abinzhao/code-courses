# 04 React

## 阶段任务

用 React 把 NoteFlow 团队后台做成可维护的组件系统，重点学习组件组合、状态设计、异步数据、路由、权限状态、测试和性能证据。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W21–W23 | JSX、组件、Props、状态、表单、副作用和自定义 Hook | 文章列表与编辑器 |
| W24–W26 | 路由、TanStack Query、Zustand、测试和性能 | 团队管理后台 |

## 阶段成果

- 登录、列表、搜索筛选、编辑表单和权限状态完整闭环。
- 区分本地状态、派生状态和服务端状态。
- 通过组件测试、Hook 测试和一条 Playwright 主流程。
- 使用 Profiler、懒加载、虚拟列表和错误边界定位问题。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第五阶段react)。
