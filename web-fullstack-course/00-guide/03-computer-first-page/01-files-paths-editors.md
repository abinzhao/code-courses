# 01 文件、路径与编辑器：确认你改的是哪一份网页

## 任务卡

王阿姨把自行车商品说明保存了两次：桌面一份、学习目录一份。她修改价格后刷新页面，浏览器却仍显示旧价格。你的任务是建立一套不会靠猜的文件工作流：认清文件与文件夹、绝对路径与相对路径、扩展名与编码，并用证据找出“改错文件”和“没有保存”。

| 项目 | 本课产出 | 验收证据 |
| --- | --- | --- |
| 练习目录 | `market-start/` 与 `index.html` | 文件树和绝对路径记录 |
| 第一张本地页面 | 浏览器显示商品标题与价格 | 地址栏、页面和源文件一致 |
| 保存实验 | 280 元改为 260 元 | 保存前后刷新对照 |
| 故障恢复 | 找出另一份同名文件 | 地址栏路径与编辑器路径对照 |

建议用 60～90 分钟完成。所有文件放在个人练习目录，不在教材仓库创建应用源码。

## 1. 任务背景

网页代码首先是磁盘上的文本。编辑器把文件读入内存，修改后只有执行保存，变化才会写回磁盘；浏览器再从某个路径读取磁盘内容，解析为当前页面。

这条链路至少包含四份状态：

```text
编辑器缓冲区中的文字
  → 保存到磁盘文件
  → 浏览器从地址栏指向的位置读取
  → 浏览器内存中的 DOM
```

“页面没变”不能直接归因于缓存。你可能没有保存、打开了另一份同名文件、扩展名实际是 `.txt`，也可能只在开发者工具中临时改了 DOM。本课先把这些边界分开。

## 2. 学习目标

完成后，你应能：

- 区分文件、文件夹、程序、进程、内存和磁盘。
- 用文件树描述目录结构，用绝对路径定位唯一文件。
- 根据当前工作目录解释相对路径会指向哪里。
- 显示并核对扩展名，识别 `index.html.txt`。
- 以 UTF-8 保存 HTML，并解释编码声明与文件编码的关系。
- 区分编辑器缓冲区、磁盘源文件与浏览器 DOM。
- 用地址栏、编辑器标题、文件信息和页面源代码诊断改错文件。
- 为邻里集市建立一个边界清楚的静态 V0 页面。

## 3. 预备知识

## 4. 核心理论

### 4.1 文件、文件夹、程序与进程

| 名词 | 本课例子 | 生命周期与边界 |
| --- | --- | --- |
| 文件 | `index.html` | 磁盘上的字节序列，保存后通常跨重启存在 |
| 文件夹 | `market-start` | 组织文件和子文件夹，本身不是网页 |
| 程序 | 编辑器、浏览器 | 可执行的软件 |
| 进程 | 正在运行的浏览器实例 | 程序运行时的资源容器，退出后结束 |
| 内存 | 未保存文字、当前 DOM | 临时状态，不保证持久存在 |
| 磁盘 | 已保存的 HTML | 持久状态，浏览器可再次读取 |

扩展名帮助系统和工具判断文件类型，但它不会改变文件内容。把普通文本重命名为 `.html`，只是告诉工具按 HTML 处理；内容仍要符合 HTML 语法。

### 4.2 文件树把“在哪里”说清楚

本课使用下面的个人目录：

```text
market-learning/
└── market-start/
    └── index.html
```

树的每一层都代表一个文件夹边界。两个不同位置可以各有一个 `index.html`：

```text
Desktop/market-start/index.html
Documents/market-learning/market-start/index.html
```

文件名相同不代表是同一个文件。诊断时需要路径，而不是只说“我改了 index”。

### 4.3 绝对路径与相对路径

绝对路径从文件系统入口开始，能在当前电脑上定位一个位置。示例：

```text
macOS:   /Users/lin/Documents/market-learning/market-start/index.html
Windows: C:\Users\Lin\Documents\market-learning\market-start\index.html
```

相对路径从一个约定的基准出发：

```text
从 market-learning 出发：market-start/index.html
从 market-start 出发：index.html
从 market-start 返回上级：../
```

相对路径本身不完整。别人问“它从哪里算起”，你必须能回答。编辑器文件浏览区通常以打开的项目目录为基准；终端命令则以当前工作目录为基准；HTML 中的相对 URL 又以当前文档 URL 为基准。

### 4.4 扩展名不是装饰

错误案例：

```text
文件管理器显示：index.html
实际完整名称：index.html.txt
```

系统隐藏扩展名时，新增文件可能被文本编辑器自动加上 `.txt`。浏览器可能把它当普通文本显示，或者系统继续用文本编辑器打开它。

正确文件名只有一个 `.html` 后缀：

```text
index.html
```

不要用 `index.htm.txt`、`index.html.rtf` 或富文本格式。代码文件应保存为纯文本。

### 4.5 编码决定字节怎样变成文字

编辑器把“邻里集市”编码为字节，浏览器再按字符编码解释字节。两端约定不一致时可能出现乱码。

本书统一使用 UTF-8。HTML 中声明：

```html
<meta charset="utf-8">
```

这条声明不能把一个已经用其他编码保存的文件自动转换成 UTF-8。必须同时满足：

1. 编辑器实际以 UTF-8 保存；
2. HTML 尽早声明 `charset="utf-8"`；
3. 经 HTTP 传输时，响应头也应使用兼容的字符集声明。

本课只处理前两项，HTTP 响应头在下一课观察。

### 4.6 保存是一次状态转移

编辑器中的未保存状态只存在于编辑器进程内：

```text
磁盘：280 元
  ↓ 编辑器打开
缓冲区：280 元
  ↓ 修改但未保存
缓冲区：260 元，磁盘仍是 280 元
  ↓ 保存
磁盘：260 元
```

浏览器刷新本地文件时重新读取磁盘，因此未保存的 260 元不会出现。编辑器标签页上的圆点、星号或“modified”提示通常表示尚未保存，但具体图标取决于编辑器。

### 4.7 源文件与 DOM 不是同一份状态

浏览器读取 HTML 后建立 DOM。你可以在 Elements 面板把 260 元临时改成 1 元，画面会变化，但磁盘文件不变。刷新后，浏览器重新读取磁盘，页面恢复为 260 元。

所以三类证据回答不同问题：

| 证据 | 回答的问题 |
| --- | --- |
| 编辑器内容 | 当前缓冲区里写了什么 |
| “查看页面源代码” | 浏览器读取到的源文本是什么 |
| Elements | 当前活动 DOM 是什么 |

修复必须落到正确的磁盘文件，再重新加载复验。

## 5. 元素、属性、API 或配置清单

| 名称 | 作用 | 最小用法 | 边界 |
| --- | --- | --- | --- |
| `.html` | 标识 HTML 文本文件 | `index.html` | 扩展名正确不代表内容合法 |
| UTF-8 | 字符编码 | 编辑器选择 UTF-8 保存 | 只写 `meta` 不会转换文件 |
| `<!doctype html>` | 请求现代标准模式 | 放在文档第一行 | 不是普通元素 |
| `html[lang]` | 声明文档主要语言 | `<html lang="zh-CN">` | 不会翻译正文 |
| `meta[charset]` | 声明 HTML 编码 | `<meta charset="utf-8">` | 应靠近文档开头 |
| `title` | 标签页和书签标题 | `<title>邻里集市</title>` | 不替代正文 `h1` |
| `data[value]` | 连接展示价格与机器值 | `<data value="28000">280 元</data>` | 本项目机器值为整数分 |
| `time[datetime]` | 连接展示时间与机器时间 | `datetime="2026-10-11T02:00:00Z"` | 本项目持久化时间使用 UTC |
| `file:` URL | 浏览器直接读取本地文件 | 双击 `index.html` | 不等同于网站的 HTTP 环境 |
| 页面源代码 | 查看浏览器读到的文本 | 浏览器菜单“查看页面源代码” | 不显示后续 DOM 临时修改 |

## 6. 最小可运行案例

### 6.1 文件位置

在个人练习区创建：

```text
market-learning/
└── market-start/
    └── path-check.html
```

用代码编辑器新建 `path-check.html`，确认右下角或状态栏显示 UTF-8，保存以下完整内容：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>路径检查页</title>
</head>
<body>
  <main>
    <h1>我打开了正确的文件</h1>
    <p>文件标记：MARKET-PATH-20261011</p>
    <p>保存状态：磁盘内容已更新</p>
  </main>
</body>
</html>
```

### 6.2 运行方式

保存后，在文件管理器中双击 `path-check.html`。无需终端和服务器。浏览器地址栏应以 `file:` 开头。

在浏览器中使用“查看页面源代码”，搜索唯一标记：

```text
MARKET-PATH-20261011
```

### 6.3 预期结果

- 标签页标题是“路径检查页”。
- 页面显示“我打开了正确的文件”。
- 页面源代码包含唯一标记。
- 编辑器标题不再显示未保存标记。
- 文件完整名称为 `path-check.html`，不是 `.txt` 或富文本文件。

### 6.4 停止与恢复

本例没有后台进程，关闭标签页即可结束。若页面显示源代码，检查完整扩展名；若中文乱码，检查编辑器实际编码和 `meta charset`；若找不到标记，当前标签页指向另一份文件。

### 6.5 明确错误示例

复制文件到桌面，再只修改学习目录中的标题。随后错误地双击桌面副本。此时：

```text
编辑器：Documents/market-learning/market-start/path-check.html
浏览器：Desktop/path-check.html
```

两个窗口都叫 `path-check.html`，但绝对路径不同。不要反复刷新或清缓存；先对照路径。

## 7. 邻里集市集成案例

在同一个 `market-start` 目录新建正式的静态首页：

```text
market-learning/
└── market-start/
    ├── index.html
    └── path-check.html
```

把下面完整代码保存为 `index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta
    name="description"
    content="邻里集市九成新自行车静态商品说明。"
  >
  <title>九成新自行车 · 邻里集市</title>
</head>
<body>
  <header>
    <h1>邻里集市</h1>
    <p>让闲置物品遇见下一位主人。</p>
  </header>
  <main>
    <article>
      <h2>九成新自行车</h2>
      <p>价格：<data value="28000">280 元</data></p>
      <p>
        发布时间：
        <time datetime="2026-10-11T02:00:00Z">
          2026年10月11日 10:00（北京时间）
        </time>
      </p>
      <p>适合周末骑行，见面验车后再决定是否交接。</p>
      <a href="#contact-note">查看联系说明</a>
    </article>
    <section id="contact-note" aria-labelledby="contact-title">
      <h2 id="contact-title">联系说明</h2>
      <p>当前是静态教学页，尚未接入账号、联系或预约功能。</p>
    </section>
  </main>
  <footer>
    <small>演示数据不会创建真实交易。</small>
  </footer>
</body>
</html>
```

双击打开。点击“查看联系说明”应跳到对应章节。`value="28000"` 表示 28000 分，即 280 元；`datetime` 使用 UTC ISO 8601，页面文字再按北京时间展示。

接着把页面文字中的 280 元改为 260 元，机器值同步改为 `26000`：

1. 先不保存，刷新，页面仍显示磁盘中的 280 元。
2. 保存，再刷新，页面显示 260 元。
3. 查看页面源代码，确认展示值与机器值都已更新。

当前页面只负责静态说明。链接是页内导航，不是假装可用的交易按钮；价格也不是服务器权威数据。

## 8. 常见错误与排查路径

### 8.1 固定诊断顺序

```text
现象
  → 记录浏览器地址栏
  → 记录编辑器文件绝对路径
  → 检查保存标记
  → 查看页面源代码
  → 判断扩展名与编码
  → 修复正确文件
  → 重新加载复验
```

### 8.2 完整故障记录：改了价格却没有变化

| 阶段 | 记录 |
| --- | --- |
| 现象 | 编辑器显示 260 元，刷新仍显示 280 元 |
| 证据 | 浏览器地址栏指向桌面副本；编辑器打开文稿目录副本 |
| 原因 | 修改和运行的是两份同名文件 |
| 修复 | 关闭桌面副本，从编辑器所在目录打开 `index.html` |
| 复验 | 地址栏路径一致，页面源代码含 `value="26000"`，页面显示 260 元 |

### 8.3 其他高频错误

| 现象 | 证据 | 原因 | 修复 | 复验 |
| --- | --- | --- | --- | --- |
| 页面显示 HTML 字符 | 完整文件名是 `.html.txt` | 扩展名错误 | 重命名为 `.html` | 重新打开后浏览器解析页面 |
| 中文乱码 | 编辑器编码不是 UTF-8 | 编码与声明不一致 | 以 UTF-8 重存 | 标题与正文正常显示 |
| 刷新仍是旧内容 | 标签页有未保存标记 | 只改了缓冲区 | 保存磁盘文件 | 源代码和页面同步变化 |
| DevTools 改价后刷新丢失 | 磁盘仍是原值 | 只改了 DOM | 回编辑器修改并保存 | 刷新后仍保留新值 |
| 页内链接不跳转 | `href` 与 `id` 不同 | 片段目标不匹配 | 统一两个标识 | 点击与键盘 Enter 都可跳转 |

## 9. 课后题

<details>
<summary>1. 文件名相同，为什么可能不是同一个文件？</summary>

文件由完整路径定位。桌面和文稿目录可以分别包含 `index.html`；只比较文件名无法判断浏览器与编辑器是否指向同一份内容。

</details>

<details>
<summary>2. 写了 meta charset，文件就一定是 UTF-8 吗？</summary>

不一定。`meta` 声明浏览器应如何解释字节，编辑器还必须实际以 UTF-8 写入字节。声明与实际编码应一致。

</details>

<details>
<summary>3. 为什么 DevTools 中改成 1 元，刷新后会恢复？</summary>

Elements 修改的是浏览器内存中的活动 DOM，没有写回磁盘源文件。刷新重新读取源文件，所以恢复为磁盘值。

</details>

<details>
<summary>4. 从 market-learning 目录出发，首页的相对路径是什么？</summary>

`market-start/index.html`。如果当前基准已经是 `market-start`，相对路径则是 `index.html`。

</details>

<details>
<summary>5. 280 元在邻里集市的机器值为什么是 28000？</summary>

项目契约以整数分保存和传输金额，避免用浮点元产生舍入歧义。280 元等于 28000 分。

</details>

## 10. 实践练习

### 10.1 基础：新增第二件静态商品

文件：`market-start/index.html`。在自行车后新增“折叠桌”，展示 68 元，机器值为 `6800`；加入从页首跳到折叠桌的页内链接。

参考答案要点：使用第二个 `article`，价格写成 `<data value="6800">68 元</data>`，目标使用唯一 `id`，不添加虚假的购买按钮。

### 10.2 进阶：画出路径基准

记录文件：`market-learning/learning-log.md`。分别写出从 `market-learning`、`market-start` 和其上级目录定位首页的相对路径，并记录首页绝对路径。

参考答案标准：答案必须明确每条路径的起点；只写 `index.html` 而不写基准不通过。

### 10.3 故障注入：制造同名副本

创建 `market-copy/index.html`，把标题改为“副本页面”。浏览器打开副本，编辑器同时修改正式首页。按“现象、证据、原因、修复、复验”写记录。

预期：两份文件互不影响。完成标准是能仅凭地址栏和绝对路径指出当前页面来源，并恢复到正式首页。禁止用删除全部副本来代替定位原因。

参考答案要点：证据至少包含两个绝对路径、两个不同标题和修复后的页面源代码标记。

## 12. 常见问题

**为什么双击 HTML 后地址以 `file:` 开头？**

浏览器正在直接读取本地文件，没有向 HTTP 服务器请求。下一课会建立本机 HTTP 服务并比较两种环境。

**必须使用 VS Code 吗？**

不必。能编辑纯文本、显示编码和保存状态即可。不要使用会自动加入富文本格式的文档软件。

**路径里能有空格或中文吗？**

文件系统通常允许，但命令行需要正确引用，跨工具时也更容易输错。初学目录使用短的 ASCII 名称可减少无关故障。

**可以只看页面画面，不看源代码吗？**

不可以作为完整验收。画面相同可能来自不同文件，页面源代码和地址栏能补足来源证据。

**删除重复文件是不是最快修复？**

先确认两份文件的用途和内容。未经确认删除可能丢失用户资料；本课只要求定位并选择正确来源。
