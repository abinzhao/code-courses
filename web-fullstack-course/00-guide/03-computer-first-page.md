# 第一课：电脑、文件与第一张网页

> 本章目标：从一个空的个人练习目录出发，做出可通过本机 HTTP 服务访问的邻里集市首页，并留下文件、请求和故障恢复证据。

## 本章任务

王阿姨想展示一辆闲置自行车。你要完成的不是一张“看起来像网页”的截图，而是一条可重复执行的链路：

```text
找到正确文件
  → 保存 UTF-8 HTML
  → 用本机服务返回页面
  → 在 DevTools 证明 200 与 404
  → 留下可复核故障记录
```

本章结束时，个人练习目录应包含：

```text
market-learning/
├── market-start/
│   ├── index.html
│   └── server.mjs
└── learning-log.md
```

教材仓库只保存教程，不替你创建这些应用文件。

## 必要前置

- 完成[版本基线](02-version-baseline.md)中的首周环境记录。
- 准备纯文本编辑器、现代浏览器和 Node.js 24 LTS。
- 能在系统文件管理器中新建文件夹并显示扩展名。
- 不需要数据库、框架、包管理器、登录或云服务。

若终端操作尚不熟悉，可以先阅读下一章第一课的目录与进程部分，再回到本章完成 HTTP 实验。

三篇教程必须按顺序完成。后面的证据依赖前面创建的个人文件。

| 顺序 | 教程 | 建议时间 | 可见产出 | 关键证据 |
| ---: | --- | ---: | --- | --- |
| 1 | [文件、路径与编辑器](03-computer-first-page/01-files-paths-editors.md) | 60～90 分钟 | UTF-8 静态首页 | 绝对路径、保存状态、同名文件恢复 |

## 三步邻里集市项目

### 第一步：建立唯一文件来源

在个人 `market-learning/market-start/` 中创建 `index.html`。页面至少包含：

- “邻里集市”一级标题；
- “九成新自行车”商品标题；
- 展示价格 280 元与机器值 28000 分；
- 带 `Z` 的 UTC 发布时间；
- 页内联系说明；
- “静态教学页，不提供真实交易”的边界说明。

通过地址栏、编辑器绝对路径和页面源代码证明浏览器打开的是同一份文件。

### 第二步：建立本机 HTTP 入口

在同一目录创建 `server.mjs`，只允许 `GET /` 和 `GET /index.html`，固定读取首页并返回：

```text
Status: 200
Content-Type: text/html; charset=utf-8
Cache-Control: no-store
```

未知路径返回 404，其他方法返回 405，文件读取失败返回不泄露内部路径的 500。服务绑定 `127.0.0.1:3000`，只用于本机教学。

### 第三步：建立证据闭环

使用 DevTools 完成两组观察：

| 正常路径 | 故障路径 |
| --- | --- |
| `GET /` 返回 200 | `GET /missing` 返回 404 |
| HTML MIME 正确 | 错误正文为纯文本 |
| 商品标题可见 | 服务仍保持运行 |
| 价格机器值为 28000 | 回到 `/` 后再次得到 200 |

再在 Elements 临时改价，刷新后证明 DOM 修改没有写回源文件。

## 综合验收

### 功能证据

- [ ] `index.html` 与 `server.mjs` 位于个人练习目录，不在教材目录。
- [ ] `node --version` 满足 Node.js 24 LTS，或已记录实际差异。
- [ ] `node server.mjs` 能启动，页面地址为 `http://127.0.0.1:3000/`。
- [ ] 首页文档请求返回 200 和正确 HTML MIME。
- [ ] `/missing` 返回 404，不伪装为 200。
- [ ] 停止服务后能识别连接失败，不把它写成 404。
- [ ] 页面含整数分机器价格与 UTC ISO 8601 机器时间。
- [ ] 静态页没有声称具备真实联系、预约、登录或持久化能力。

### 机制解释

现场用 5 分钟说明：

1. 编辑器缓冲区、磁盘文件和 DOM 有什么不同；
2. 绝对路径与相对路径各自需要什么基准；
3. `file:` 与 HTTP 在状态码、响应头和服务进程上的差异；
4. URL 的路径、查询与片段分别由谁处理；
5. 200、404、500 和连接失败为什么不能混为一谈；
6. Network Response、Sources 与 Elements 为什么可能不同。

### 故障恢复

至少提交一份完整记录，必须包含：

```text
现象
复现步骤
输入与环境
Network 或 Console 证据
原因
最小修复
相同步骤复验
当前能力边界
```

推荐使用“错误路径 404”作为第一次记录；额外完成同名文件、错误 MIME 或未保存故障可作为加分证据。

### 章级交付

提交或展示：

- 个人文件树与首页绝对路径；
- Node.js 原始版本输出；
- 启动与停止命令；
- 首页 200、错误路径 404、停止服务后三种记录；
- 一次 Elements 临时修改与刷新恢复；
- 一份五阶段故障报告。

只展示最终页面截图不能通过；只提交代码但无法解释请求链路也不能通过。

## 学习边界

本章服务用于理解文件、URL 和 HTTP，不是通用静态服务器。它没有生产级路径处理、压缩、缓存、TLS、访问日志、限流或安全加固。后续卷会在各自职责内逐层建立这些能力。

当前商品数据是静态教学内容。前端显示的 280 元不是权威交易价格；真实价格、商品状态和权限必须由后续服务端校验。
