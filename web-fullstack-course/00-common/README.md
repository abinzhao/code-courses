# 00 Web 与 HTML 基础

## 阶段任务

这一阶段建立所有后续前端工作的共同地基：理解页面如何被加载，使用语义化 HTML 表达内容，使用原生表单完成输入，并从键盘和屏幕阅读器角度检查页面。

## 周次地图

| 周次 | 学习重点 | 阶段成果 |
| --- | --- | --- |
| W1 | Web 应用、浏览器、服务器、终端、文件系统和 Git | 建立本地开发环境，提交第一个项目 |
| W2 | HTML 文档结构、`head`、元信息、标题和文本语义 | NoteFlow 公共首页骨架 |
| W3 | 列表、链接、表格、图片、音视频和嵌入 | 内容目录和媒体展示页 |
| W4 | 表单、输入属性、原生校验、对话框、模板和可访问性 | 文章编辑表单和键盘验收 |

通过 W1 需要提交：

建议按以下顺序完成：

```text
U01 教程 -> U01 实验 -> U02 教程 -> U02 实验 -> W1 验收
```

## 阶段验收方向

到 W4 结束时，学习者应能：

- 使用 HTML 表达文档结构、内容关系和交互语义。
- 为表单选择合适的输入类型、属性和原生校验。
- 解释标题层级、地标、表头关联和键盘焦点。
- 使用浏览器工具验证页面结构、请求和可访问性问题。
- 说明废弃写法的历史用途，并给出现代替代方案。

## 与 NoteFlow 的关系

公共内容侧从一张静态草图开始，逐步变成：

```text
文章入口 -> 文章目录 -> 媒体内容 -> 编辑表单 -> 可访问发布页面
```

这一阶段不引入 React、Vue 或后端 API。先让浏览器能可靠理解内容，后面才有稳定的组件、接口和数据模型可依赖。
