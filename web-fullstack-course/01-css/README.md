# 01 CSS 全体系

## 阶段任务

把 W1–W4 的可访问内容变成可维护、响应式、可主题化的 NoteFlow 页面。学习重点覆盖选择器、层叠、盒模型、Flexbox、Grid、容器查询、逻辑属性、主题变量、动画和 DevTools 排错。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W5–W8 | 选择器、盒模型、布局、字体、颜色和尺寸函数 | 文章卡片、导航、表单和后台布局 |
| W9–W12 | 响应式、现代选择器、遮罩、动效和性能 | 多端公共首页和主题系统 |

## 阶段成果

- 手机、平板、桌面三类视口下稳定显示。
- 至少一套深色主题和用户偏好适配。
- 有目的的加载、反馈和页面过渡动画。
- 支持 `prefers-reduced-motion`。
- 能用 DevTools 解释一个布局问题和一个性能问题。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第二阶段css-全体系)。
