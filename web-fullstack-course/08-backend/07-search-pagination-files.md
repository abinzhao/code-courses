# 07 搜索、分页与文件：约束动态输入和资源边界

## 本章使命

把“列表可筛选、可以一直翻页、用户可以上传图片”拆成三个可验证的后端问题：

1. 动态查询只能从服务端白名单选择 SQL 结构，用户值始终参数化，字面搜索正确转义；
2. 分页必须有全序，游标必须可验证，并能解释并发新增、删除和排序字段更新的影响；
3. 文件按流接收，在写入期间限制总字节，按签名字节初筛类型，使用服务端键隔离存储并清理失败产物。

本章不会把扩展片段拼成第二套完整 API。第 10 章仍是综合项目源码的唯一所有者，而且其最小
范围**不实现生产文件上传或对象存储**。文件课提供独立的本机摄取实验和生产设计清单，不能据此
声称综合项目已经具备上传能力。

## 必要前置与边界

- 已完成[参数化 SQL 与 SQLSTATE](04-postgres-data-access/02-parameterized-sql-types-sqlstate.md)；
- 理解[事务、锁与并发](05-transactions-concurrency.md)；
- 理解[Cookie 会话、CSRF 与对象授权](06-auth-sessions-rbac.md)；
- 使用 Node.js 24；涉及查询计划的步骤需要读者自己的 PostgreSQL 18 测试库；
- 教材仓库不创建应用工程、不保存上传文件、不连接真实对象存储。

所有商品金额继续使用非负安全整数分，时间继续使用 UTC ISO 8601。示例中的商品、用户和文件
都是教学数据；纯 Node 案例、内存数组和假仓储会明确标为 `MOCK/STATIC`。

## 章级邻里集市任务

为邻里集市设计“公共商品发现与图片摄取”边界：

1. `q` 最长 100 个字符，`%`、`_` 和 `\` 按字面量搜索；
2. `sort` 只能选择 `newest`、`price_asc`、`price_desc`，不能直接进入 SQL；
3. Offset 列表固定 `created_at DESC, id DESC`，Keyset feed 的游标绑定同一排序；
4. 游标负载只接受版本、规范 UTC 和 UUID，Base64URL 只是编码，不是信任证明；
5. 上传在流经应用时限制字节，不先读入一个完整 `Buffer`；
6. 客户端文件名和 MIME 不决定存储路径或真实类型；
7. 临时文件只有校验成功才提升到隔离对象目录，任一步失败都清理本次产物；
8. 下载从业务元数据解析服务端键，默认 `attachment` 并设置 `nosniff`。

## 综合验收与证据

| 证据 | 合格判定 | 不能推出的结论 |
| --- | --- | --- |
| 纯 Node 查询编译测试 | SQL 结构只来自白名单，值只出现在参数数组，通配符已转义 | SQL 已在 PostgreSQL 执行 |
| PostgreSQL 计划记录 | 记录服务端/客户端 18、连接目标、迁移状态和实际 `EXPLAIN` 输出 | 生产数据分布与测试库相同 |
| Offset/Keyset 静态实验 | 固定数据下能观察插入导致 Offset 重复，而 Keyset 保持锚点 | 所有更新场景都无重复或遗漏 |
| 游标破坏实验 | 非法 Base64URL、版本、UTC、UUID、排序不匹配均被拒绝 | 游标已经保密或防篡改 |
| 本机文件流实验 | 小 PNG/JPEG 签名通过，超限/错误签名失败且临时文件被清理 | 文件已完整解码、杀毒或安全发布 |
| 下载设计审查 | 路径不采用客户端文件名，响应设置 attachment/nosniff | CDN、对象存储和权限已部署 |

章级完成条件：

- [ ] 能区分值参数化、标识符白名单和 `LIKE` 字面转义；
- [ ] 能解释为什么 `ORDER BY created_at DESC` 不是稳定全序；
- [ ] 能写出 `(created_at, id) < (...)` 的降序 Keyset 条件；
- [ ] 能说明 Base64URL、签名游标和加密游标的不同承诺；
- [ ] 能用失败证据证明超限流不会留下本次半文件；
- [ ] 已明确记录 PostgreSQL、HTTP、对象存储和恶意文件扫描中哪些步骤没有实际运行。

## 证据边界

纯 Node 案例可以证明字符串编译、游标解析和流清理逻辑在该进程中可观察，不能证明 PostgreSQL
查询语义、HTTP 代理限制、多副本共享存储或对象存储权限。`EXPLAIN (ANALYZE, BUFFERS)` 会真实
执行查询，只能在授权测试库使用；没有实际输出时只能保留待运行命令。

签名字节只是格式初筛。即使文件头匹配 PNG，也仍可能是损坏文件、解码炸弹或含恶意载荷的复合
文件。生产图片链路还需要受限解码、像素上限、重新编码、恶意内容扫描、对象存储权限、配额、
生命周期和审计，本章不把这些外部能力写成已通过。
