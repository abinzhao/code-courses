## 使用规则

1. 阅读某行时，至少检查理论、案例、诊断和验收四个链接，不能只凭知识点名称判断已覆盖。
2. PostgreSQL、HTTP、Redis 与 BullMQ 的运行结论必须来自相应服务的实际输出；TypeScript 编译、SQL 文本检查和预期输出不能替代它们。
3. 综合项目不实现真实支付、邮件、生产上传存储或强制 Redis；这些排除项不应被覆盖矩阵误读为已交付能力。
4. 资料与兼容性快照日期为 2026-10-11；后续升级版本时，先更新版本探针和正文，再更新本矩阵。
