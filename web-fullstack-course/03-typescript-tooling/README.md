# 03 TypeScript 与工具基础

## 阶段任务

把原生 JavaScript 能力提升为可维护的类型安全项目，理解函数、对象、异步、模块、Node.js 运行时、TypeScript 类型系统和 Vite 构建边界。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W17–W18 | 函数、闭包、对象模型、Promise、并发和取消 | 可复用数据模块与搜索聚合器 |
| W19–W20 | ESM、Node.js、TypeScript、pnpm 和 Vite | 命令行工具和类型安全前端项目 |

## 阶段成果

- 能解释闭包、`this`、原型链、Promise 和事件循环。
- 能区分浏览器 API、Node.js API、ESM 和 CommonJS。
- 能从类型收窄、模块边界和测试角度组织代码。
- 能从干净目录执行安装、类型检查、测试和构建。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第四阶段javascripttypescript-与工具)。
