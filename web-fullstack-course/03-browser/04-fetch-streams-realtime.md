# 04 · 请求、流与实时通信

> 本章任务：把邻里集市的网络读取从“能发请求”推进到“能取消、能恢复、能说明消息边界与一致性边界”。

## 本章产出

- 一个能区分 HTTP 错误、网络失败、超时、主动取消和旧响应的商品搜索页；
- 一个能从任意 UTF-8 字节块恢复 NDJSON 商品帧的增量读取器；
- 一个带连接状态、事件游标、断线恢复和重复抑制的 SSE/轮询看板；
- 一份包含现象、证据、原因、修复与复验的网络故障记录。

所有实验都使用本机公开演示数据，不实现真实认证、持久化或生产消息系统。写操作的幂等、事务和对象授权由后端卷继续展开。

## 必要前置

1. 完成[存储、会话与安全边界](03-storage-security.md)，能区分同源、Cookie、CORS 与对象授权；
2. 按[本卷 browser-lab 契约](README.md#多文件实验怎样启动)准备 Node.js 24 与本地目录；
3. 会使用 Promise、`async` / `await`、DOM 事件和 DevTools Network；
4. 端口冲突时先确认进程归属，不终止其他项目进程。

## 章级邻里集市任务

构建“商品搜索与状态看板”：

```text
搜索表单
  ├─ GET 商品：超时、取消、有限重试、旧响应防护
  ├─ NDJSON 导出：逐条验证、可取消、大小与条数上限
  └─ 状态通知：SSE 优先、轮询回退、游标恢复、重复抑制
```

必须保留以下领域约束：

- 价格存储与传输使用整数分，只在显示边界格式化；
- 事件时间使用 UTC ISO 8601，显示时才本地化；
- 缓存或离线快照必须标注时间，不能证明商品当前可预约；
- 通知事件只触发刷新，预约成功仍由服务端事务与对象授权决定；
- 不在 URL、页面、截图或日志中放 Token、Cookie 和私人商品信息。

## 综合验收

- [ ] 三篇教程均按各自文件清单从空目录运行；
- [ ] 正常、空结果、HTTP 失败、超时、取消和竞态有可区分证据；
- [ ] NDJSON 在汉字与 JSON 跨块时仍正确，畸形行与超长行可控失败；
- [ ] SSE 主动断线后显示重连状态，回放事件不会重复渲染；
- [ ] 停止或离开页面后没有遗留请求、reader、EventSource 或轮询循环；
- [ ] 诊断记录包含环境、固定动作、Network/Console 证据、原因、修复和同条件复验；
- [ ] 能说明本地实验未验证公网代理缓冲、生产容量、真实会话、Safari/Firefox 和移动网络；
- [ ] 不能用“连接成功”“已取消”或“事件已到达”替代业务一致性结论。
