## 1. 使用方式

| 标记 | 含义 |
| --- | --- |
| `§4` | 机制、状态或协议推导 |
| `§6` | 含文件位置、创建方式、命令、预期结果和失败证据的最小案例 |
| `§7` | 邻里集市领域集成、安全/离线/性能边界 |
| `§8` | 明确错误示例与“现象、证据、原因、修复、复验”记录 |
