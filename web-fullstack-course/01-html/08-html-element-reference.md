# 第八章：元素参考、历史与迁移

> 把前七章的机制整理成可检索索引，并能识别旧标记为什么仍会显示、为什么仍不该写进现代页面。

## 本章任务

完成前七章后，你不需要背诵标签名称，而需要建立两种能力：

1. 从内容职责反查合适元素、属性、DOM 接口和默认行为；
2. 面对旧商品页时，区分“浏览器仍能解析”和“新代码应继续使用”。

本章的详细教程分别承担“现行参考”和“历史迁移”。章入口只说明查阅方法、全卷审计和迁移验收，不复制完整索引。

## 学习成果

完成本章后，你将拥有：

- 一份按职责而不是只按字母排序的元素/属性/API 索引；
- 一套从需求、内容模型、默认行为和兼容性选择元素的方法；
- 一张现行、有限支持、实验扩展、过时和非标准特性的区分表；
- 一份旧商品页的迁移前后对照；
- 一次覆盖全部八章的 HTML 阶段审计。

## 选择元素的六步法

```text
1. 内容或操作是什么？
2. 是否存在更具体的原生元素？
3. 允许放在当前父元素中吗？
4. 浏览器默认提供什么语义与行为？
5. 需要哪些属性、机器值或 DOM 接口？
6. 目标浏览器和辅助技术中怎样验证？
```

如果答案从“设计稿看起来像什么”开始，通常还没有完成语义判断。

## 历史迁移范围

迁移教程按旧用途分组：

- 呈现：`font`、`center`、`big`、`tt`、`strike`；
- 框架布局：`frameset`、`frame`、`noframes`；
- 插件：`applet` 和旧插件参数；
- 滚动/闪烁：`marquee`、`blink`；
- 术语：`acronym`；
- 旧呈现属性：`align`、`bgcolor`、`border`、`cellpadding`、`cellspacing`；
- 脚本声明：旧 `language` 属性；
- 浏览器容错与现代规范的区别。

每类迁移都必须保留：

1. 旧代码和原始意图；
2. 当前 HTML/CSS/脚本替代；
3. 迁移步骤；
4. 可见回归风险；
5. DOM、键盘、无障碍和浏览器验证。

## 章级综合任务：迁移旧商品页

### 输入

在个人目录创建 `legacy-listing.html`，有意包含：

- `center` 和 `font` 控制标题；
- 表格属性控制边框和间距；
- `marquee` 显示安全提醒；
- `strike` 显示旧价格；
- `acronym` 解释 LED；
- `language="javascript"`；
- 一个旧 frame 布局说明片段；
- 一个旧 applet 插件说明片段。

旧代码只用于本地迁移练习，不复制到生产页面。

### 输出

`modern-listing.html` 应使用：

- 正确文档骨架、lang、title 和 viewport；
- 页级结构、article 和显式标题；
- CSS 负责居中、字体、颜色、边框和间距；
- 静止且可见的安全提醒，若确需运动则尊重减少动效；
- `s` 或 `del` 按真实含义表达旧内容；
- `abbr` 和可见全称；
- 现代 script 属性；
- 普通页面布局和链接替代 frame；
- 当前嵌入方式或普通下载/打开链接替代插件；
- 整数分和 UTC 时间契约；
- 明确的静态/内存能力边界。

## HTML 阶段总审计

从个人练习中选择最终商品站，逐章检查。

### 第一、二章

- 文档模式、语言、元信息和资源顺序；
- 标题、文本语义、国际化和修订；
- 地标、标题、链接、URL 与内容分组。

### 第三至第五章

- 图片候选、替代文本、媒体和嵌入边界；
- 表头关系、响应式表格和安全 DOM 生成；
- successful controls、全部 input 类型和验证恢复。

### 第六、七章

- 原生交互、DOM、事件、模板和组件生命周期；
- 键盘、焦点、动态状态、媒体替代；
- 元信息、HTTP 状态和结构化数据一致性。

### 第八章

- 每个元素都有内容职责；
- 有限支持特性有检测或回退；
- 旧标签/属性不进入现代主线；
- 所有兼容性声明有核验日期和目标范围。
