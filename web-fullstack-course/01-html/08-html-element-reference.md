# 第八章：元素参考、选择与纠错

> 把前七章的机制整理成可检索索引，并能从需求职责选择现行元素、属性与 DOM 行为。

## 本章任务

完成前七章后，你不需要背诵标签名称，而需要建立两种能力：

1. 从内容职责反查合适元素、属性、DOM 接口和默认行为；
2. 面对源文件与 DOM 分歧时，按确定性证据定位 owner 并完成最小修复。

本章的详细教程分别承担“现行参考”“属性与默认行为”和“选择与纠错”。章入口只说明查阅方法、
全卷审计和综合验收，不复制完整索引。

## 学习成果

完成本章后，你将拥有：

- 一份按职责而不是只按字母排序的元素/属性/API 索引；
- 一套从需求、内容模型、默认行为和兼容性选择元素的方法；
- 一套区分 HTML、DOM、CSS、应用状态与服务端状态的 owner 规则；
- 一份源文件、DOM、可访问性树与请求证据的纠错记录；
- 一次覆盖全部八章的 HTML 阶段审计。

## 选择元素的六步法

```text
1. 内容或操作是什么？
2. 是否存在更具体的原生元素？
3. 允许放在当前父元素中吗？
4. 浏览器默认提供什么语义与行为？
5. 需要哪些属性、机器值或 DOM 接口？
6. 目标浏览器和辅助技术中怎样验证？
```

如果答案从“设计稿看起来像什么”开始，通常还没有完成语义判断。

- 文档根、元信息和资源；
- 分节、地标和标题；

- 图片、媒体、嵌入、SVG/MathML；
- 表格；
- 表单和所有现行 input 类型；
- 原生交互、脚本、模板和组件；
- 全局属性、ARIA 边界和 DOM 接口。

每组至少给出：

```text
用途

最小示例

```

HTML 是 Living Standard。核验日期只说明教材快照，不把标准冻结成“HTML6”版本清单。

## 现行选择与纠错范围

第三课按当前页面职责组织：

- 内容关系：标题、段落、机器值和时间；
- 导航与命令：链接、按钮、submitter 与默认行为；
- 资源：图片、媒体、嵌入、下载与失败替代；
- 状态：内容属性、DOM 属性、CSS、应用与服务端 owner；
- 解析：源文件、DOM 和可访问性树的差异；
- 纠错：固定输入、最小修改、同路径复验与新数据迁移。

每次纠错都必须保留：

1. 固定 URL、输入、视口和预期；
2. 源文件、DOM、Accessibility 与 Network 证据；
3. 问题 owner 与最小修复；
4. 键盘、资源失败、长内容和缩放回归；
5. 相同路径的修复后结果。

## HTML 阶段总审计

从个人练习中选择最终商品站，逐章检查。

### 第一、二章

- 文档模式、语言、元信息和资源顺序；
- 标题、文本语义、国际化和修订；
- 地标、标题、链接、URL 与内容分组。

### 第三至第五章

- 图片候选、替代文本、媒体和嵌入边界；
- 表头关系、响应式表格和安全 DOM 生成；
- successful controls、全部 input 类型和验证恢复。

### 第六、七章

- 原生交互、DOM、事件、模板和组件生命周期；
- 键盘、焦点、动态状态、媒体替代；
- 元信息、HTTP 状态和结构化数据一致性。

### 第八章

- 每个元素都有内容职责；
- 有限支持特性有检测或回退；
- 内容属性、DOM 属性、CSS 与应用状态职责清楚；
- 浏览器纠错没有被当作正确源代码；
- 所有兼容性声明有核验日期和目标范围。
