# 第二章：页面结构、链接与列表

> 把一张能阅读的商品说明，变成可以按区域、标题、目录和跨页链接访问的小型网站。

## 本章任务

台灯详情内容已经正确，但小林遇到三个问题：

1. 页面变长后找不到交接规则；
2. “返回帮助页”和“收藏商品”看起来都是可点击文字，却承担不同动作；
3. 商品特点、交接步骤和状态说明全部写成段落，关系不清楚。

本章将把页面整理成：

```text
清楚的地标和标题
  + 可预测的 URL 与链接
  + 符合内容关系的列表和分组
```

## 学习成果

完成本章后，你将拥有：

- 一个可以按地标和标题浏览的商品详情；
- 一个有主导航、商品目录和跳过导航入口的页面；
- 一组可以往返的商品页与帮助页；
- 合法嵌套的特点与交接步骤；
- 状态名称与说明；
- 一次错误片段、一次错误嵌套和一次不安全链接修复记录。

## 知识依赖图

```text
第一章的完整文档
  → 页面级和文章级结构
  → 标题与地标导航
  → URL 基准和链接目标
  → 同页目录与跨页帮助
  → 集合、流程、名称值和可引用内容
```

结构决定“内容属于哪里”，链接决定“读者去哪里”，列表和分组决定“这些内容是什么关系”。它们不是 CSS 布局的不同写法。

## 本章知识地图

### 页面结构

- `header`、`nav`、`main`、`article`、`section`；
- `aside`、`footer`、`address`、`search`；
- `h1` 至 `h6`、`hgroup`；
- 地标、标题导航、DOM 顺序和视觉位置。

### URL 与链接

- 协议、主机、端口、路径、查询和片段；
- 文档基准、相对、根相对和绝对 URL；
- `href`、`target`、`rel`、`download`；
- `hreflang`、`type`、`referrerpolicy` 和 `ping` 边界；
- 链接与按钮、安全新标签与不可信 URL。

### 列表与内容分组

- `ul`、`ol`、`li`、`menu`；
- `dl`、`dt`、`dd`；
- `figure`、`figcaption`；
- `blockquote`、`pre`、`div`、`hr`；
- 列表、描述列表、表格和分节的选择。

详细落点见 [HTML 教学覆盖矩阵](HTML-COVERAGE.md)。

## 章级综合案例

### 文件结构

```text
market-learning/
└── practice/
    └── html-chapter-02/
        ├── index.html
        └── help.html
```

两个文件都要有完整文档骨架。它们由详细教程中的案例逐步组成，不依赖框架或真实 API。

### 商品页要求

- 页级 header、主导航、一个可见 main 和页级 footer；
- 独立商品 article，包含自己的 header 和 footer；
- 商品特点、商品信息、交接流程和安全提醒；
- 主导航与商品目录具有可区分名称；
- 跳过导航链接指向主要内容；
- 同页目录目标 ID 唯一；
- 帮助页链接使用可预测的相对 URL；
- 收藏和预约如果尚未实现，只使用明确按钮和教学边界说明。

### 帮助页要求

- 可以返回商品页的具体位置；
- 使用有序列表说明交接步骤；
- 使用描述列表解释状态机器值；
- 链接文字说明目标，不只写“点击这里”；
- 不使用根相对 URL 依赖本机磁盘根。

## 综合观察

完成两个文件后：

1. 关闭所有作者 CSS，确认内容顺序仍然清楚；
2. 使用 Tab 和 Shift+Tab 遍历链接；
3. 使用 Enter 激活目录和跨页链接；
4. 观察地址栏片段和浏览器历史；
5. 在 Elements 检查地标、标题和列表父子关系；
6. 确认所有 ID 唯一。

## 章级故障演练

### 故障一：重复且未命名的导航

让主导航和商品目录都只有 `nav`，删除可访问名称。记录 Accessibility 树中是否容易区分，再恢复名称。

### 故障二：不存在的片段

把 `href="#rules"` 改成 `href="#rule"`。记录地址变化、目标查找和修复后的复验。

### 故障三：`file:` 下的根相对路径

把帮助链接改为 `/help.html`，直接打开本地文件，观察目标路径。恢复为同目录相对地址。

### 故障四：子列表位置错误

把子 `ul` 移到父 `li` 外。页面可能仍有缩进，但 Elements 中父子关系不正确。恢复结构并复验。

### 故障五：链接冒充按钮

使用 `<a href="#">收藏</a>`，观察地址和历史变化。恢复为 `button type="button"`，并明确它尚未绑定业务行为。

## 本章验收

### 页面结构

- [ ] 页面有一个可见主要内容；
- [ ] 页级和文章级结构能解释；
- [ ] 标题层级与内容从属一致；
- [ ] 多个导航可以区分；
- [ ] DOM 顺序在无样式时仍可读。

### 导航

- [ ] 能预测相对 URL 最终目标；
- [ ] 同页片段都有唯一目标；
- [ ] 商品页和帮助页可以往返；
- [ ] 链接与按钮职责正确；
- [ ] 新标签链接包含必要关系与读者提示；
- [ ] 不把不可信输入拼成危险 URL。

### 内容关系

- [ ] 特点使用无序列表；
- [ ] 交接流程使用有序列表；
- [ ] 子列表位于所属 `li`；
- [ ] 状态名称和值使用描述列表；
- [ ] 代码整体与图注关系正确；
- [ ] 长引用与作者正文可以区分。
