# 第四章：表格与二维数据

> 把多件商品放进可比较的行列模型，并在小屏、键盘、打印和脚本更新后继续保留表头关系。

## 本章任务

邻里集市要比较台灯、折叠椅和书架的价格、状态与发布时间。卡片适合逐件浏览，却让“哪件最便宜”“哪些仍可预约”需要来回查找。

你要建立一张真正的二维数据表，并回答：

- 什么内容值得进入表格，什么内容仍应使用列表、`dl` 或文章；
- 每个数据格怎样找到对应行头和列头；
- 合并单元格后实际网格位置怎样变化；
- 小屏横向滚动时怎样保留可读性和键盘路径；
- JavaScript 更新行以后，标题、表头、整数分和空状态怎样继续成立。

## 学习成果

完成本章后，你将拥有：

- 一张带 `caption`、行组、列头和行头的商品比较表；
- 一张可解释 `scope`、`headers`、`colspan` 和 `rowspan` 的多级表；
- 一份逐格网格坐标与表头关联记录；
- 一个从内存数组安全生成行、汇总整数分并处理空状态的案例；
- 一套小屏、键盘、无样式、打印和目标读屏组合的检查清单。

## 本章知识地图

### 数据模型

- `table` 与非表格内容的选择；
- `caption`、`thead`、`tbody`、`tfoot`；
- `tr`、`th`、`td`；
- 显式行组与浏览器生成的 `tbody`。

### 表头与网格

- `scope="row|col|rowgroup|colgroup"`；
- `id`/`headers` 的显式复杂关联；
- 唯一 ID 与失效引用；
- `colspan`、`rowspan` 和网格位置；
- `colgroup`、`col` 的职责与限制。

### 响应与脚本

- 横向滚动容器、键盘入口和可见焦点；
- 长内容、打印与 `table-layout`；
- 避免破坏表格 display 语义；
- `HTMLTableElement`、rows/cells 动态集合；
- insert/delete row/cell；
- `createElement` 与 `textContent` 安全生成。

逐知识点验收位置见 [HTML 教学覆盖矩阵](HTML-COVERAGE.md) 的 TBL 组。

## 章级综合案例：商品比较工作表

### 个人目录

```text
market-learning/
└── practice/
    └── html-chapter-04/
        ├── index.html
        ├── print.css
        └── table-check.md
```

教材仓库不创建运行源码。`index.html` 使用内联教学数组，不请求真实商品 API，也不把内存数据描述成服务器数据。

### 表格要求

- `caption` 明确说明表格主题和数据范围；
- 列表头包含商品、价格、状态和发布时间；
- 商品名使用行表头；
- 价格机器值使用整数分，展示边界再格式化为元；
- 时间源值为 UTC ISO，展示文字明确时区；
- 多级表头只在真实分组需要时使用；
- `scope` 或 `headers` 关系可以逐格解释；
- 跨格后的每一行占用相同网格宽度；
- 空数组显示明确空状态，不留下只有表头的误导结果；
- 动态商品文字通过 `textContent` 写入；
- 页面明确说明排序、筛选、保存、权限和并发尚未实现。

### 交互与输出

允许本章实现的行为：

- 从固定内存数组生成数据行；
- 增加或删除教学数据行；
- 重新计算整数分合计；
- 输出当前行数和空状态；
- 运行 `console.assert` 检查行数、总价和状态映射。

不在本章实现：

- 服务端分页或排序；
- 登录、权限或并发版本控制；
- 真实预约、成交或财务统计；
- 将表头按钮改造成完整 ARIA grid。

## 章级故障演练

### 故障一：用表格做页面布局

把导航、正文和侧栏放进无 `caption` 的表格。记录它为什么没有稳定二维数据，再恢复为第二章的结构元素和 CSS 布局。

### 故障二：跨格后网格错位

让一行 `colspan` 多占一列。画出每个单元格位置，比较源代码单元格数与实际网格宽度，修正后再检查后续行。

### 故障三：`headers` 指向不存在的 ID

破坏一个表头 ID。页面外观通常不变；用 DOM 查询和检查器找到悬空引用，再恢复唯一 ID。

### 故障四：响应式样式破坏表格角色

把 `table`、`tr`、`td` 全改成 `display:block`，比较目标浏览器无障碍树。恢复为滚动容器方案，保留原生结构。

### 故障五：不可信标题进入 `innerHTML`

把商品标题设为包含标签的字符串并用 `innerHTML` 插入。记录 DOM 变化，恢复 `textContent`，确认字符串只作为文字出现。

### 故障六：价格单位混合

在同一数组混入 39 元与 2500 分，再求和。通过断言暴露错误，统一为整数分后复验。

## 本章验收

### 模型与表头

- [ ] 能说明表格相对 `dl`、列表和卡片的选择依据；
- [ ] 表格有准确 `caption`；
- [ ] 行组、行、表头和数据格职责清楚；
- [ ] 简单表优先使用可解释的 `scope`；
- [ ] 复杂关联的 `headers` 全部指向同表唯一 `th[id]`；
- [ ] 跨格后网格位置没有重叠或缺口。

### 响应与动态行为

- [ ] 小屏可以滚动，不靠极小字号压缩；
- [ ] 可聚焦滚动区有名称和可见焦点；
- [ ] 打印预览不会丢失关键列和表头；
- [ ] 动态新增行仍包含行表头；
- [ ] 用户文字使用安全 DOM API；
- [ ] 内存集合、行数、状态和整数分合计有断言；
- [ ] 空状态不会伪装成加载成功的空数据。

### 手动范围

- [ ] 用键盘进入并离开滚动区域；
- [ ] 在至少一个目标读屏组合中抽查简单表；
- [ ] 复杂表未实测时明确记录；
- [ ] Safari、Firefox 或打印差异未验证时不作普遍保证。
