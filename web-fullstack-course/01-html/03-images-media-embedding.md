# 第三章：图片、媒体与嵌入

> 让商品媒体既能被浏览器正确选择和加载，也能在资源失败、键盘操作或非视觉环境中保留等价信息。

## 本章任务

邻里集市的商品页已经可以导航，但加入照片、验货视频和外部规则后出现了新问题：

1. 手机下载了远超显示尺寸的大图；
2. 图片失败后只剩文件名，商品瑕疵信息一起丢失；
3. 视频有画面却没有字幕，脚本调用播放时偶尔报错；
4. 第三方页面拒绝嵌入，父页也无法读取它的 DOM；
5. Canvas 柱形图看得见，却没有可读取的数据关系。

本章把这些问题整理为三条主线：

```text
图片候选与替代信息
  → 音视频资源、字幕和播放状态
  → 嵌入边界、SVG 与 Canvas
```

## 学习成果

完成本章后，你将拥有：

- 一组能解释候选选择过程的响应式商品图片；
- 一份图片加载、解码和失败恢复记录；
- 一个带原生控件、字幕契约和播放拒绝处理的验货媒体页；
- 一个受限的规则卡嵌入与跨源边界说明；
- 一张带文本和表格替代的商品价格图；
- 一份说明哪些验证必须依赖真实资源、Network、辅助技术或其他浏览器的范围记录。

## 本章知识地图

### 图片

- 情景化 `alt`、装饰图和链接图；
- 固有尺寸、显示尺寸与布局偏移；
- `srcset`、`sizes`、`picture` 和 `currentSrc`；
- `loading`、`decoding`、`fetchpriority`；
- CORS、referrer、解码与失败状态。

- `track`、WebVTT、字幕、描述和章节；
- `play()` Promise、媒体状态与事件；
- 网络失败、格式失败和策略拒绝的区分。

### 嵌入与图形

- `iframe`、`srcdoc`、sandbox、allow 和 frame denial；
- 同源限制、`object`、`embed` 与普通链接回退；
- `map`、`area` 与键盘可访问的文本路径；
- 内联/外部 SVG；
- Canvas 尺寸、像素密度、跨源污染和等价数据。

## 章级综合案例：商品媒体检查页

### 个人目录

```text
market-learning/
└── practice/
    └── html-chapter-03/
        ├── index.html
        ├── captions-zh.vtt
        └── media/
            ├── lamp-640.jpg
            ├── lamp-1280.jpg
            └── lamp-inspection.mp4
```

教材仓库只交付 Markdown。照片、视频和字幕由学习者在个人目录准备，并确保拥有使用权；不得把不存在的文件名、破图或远程占位资源当作成功结果。

### 页面要求

`index.html` 至少包含：

- 一张首屏商品主图，具有准确 `alt`、`width`、`height`；
- 一组 `srcset`/`sizes` 候选，并记录两个视口下的 `currentSrc`；
- 一组 `picture` 美术方向或格式回退；
- 一段带 controls 的验货视频；
- 一条中文 captions 轨道和明确的无视频回退链接；
- 一个不会假装自动播放必然成功的播放按钮；
- 一个带 `title` 与最小 sandbox 权限的静态规则嵌入；
- 一个内联 SVG 商品结构图；
- 一个 Canvas 价格图，以及同数据的文字或表格；
- 价格机器值使用整数分，时间机器值使用 UTC；
- 明确说明页面没有上传、转码、持久化、授权或支付能力。

Network 中“请求成功”只证明资源传输，不证明替代文本、字幕含义或键盘路径正确；页面截图也不能证明媒体错误恢复和跨源边界。

## 章级故障演练

### 故障一：图片候选与槽位不一致

故意把 `sizes` 写成不符合实际布局的宽度。记录浏览器选择的候选、传输尺寸和修复后的 `currentSrc`。候选选择受实现和缓存影响，不把某个固定文件名写成跨设备保证。

### 故障二：重要图片使用空替代

把商品瑕疵图改为 `alt=""`。检查无障碍树和断图状态，再恢复能替代当前图片用途的文字。

### 故障三：脚本播放被拒绝

在没有用户激活时调用 `play()`，记录 Promise 拒绝名称和页面恢复提示。修复为由清楚按钮触发，并仍保留原生 controls。

### 故障四：字幕文件语法错误

破坏 `WEBVTT` 头或时间范围。检查字幕菜单、Console/Network 和文件内容，再恢复并复验有效 cue。

### 故障五：跨源 Canvas 读取失败

用没有合适 CORS 响应的图片绘制后尝试读取像素。记录安全异常，说明正确修复在资源服务器和请求模式，而不是吞掉错误。

## 本章验收

### 图片

- [ ] 信息图片与装饰图片的替代策略不同；
- [ ] 图片在加载前预留稳定比例；
- [ ] 能解释 `srcset` 与 `sizes` 的共同作用；
- [ ] 使用 `currentSrc` 而不是猜测候选；
- [ ] 能区分加载完成、解码成功和资源可用。

### 音视频

- [ ] 原生 controls 可以通过键盘操作；
- [ ] 不依赖带声 autoplay；
- [ ] `play()` 的 Promise 有成功与失败路径；
- [ ] 字幕类型、语言、标签和 WebVTT 内容一致；
- [ ] 说明了字幕、逐字稿和音频描述的不同责任。

### 嵌入与图形

- [ ] iframe 有名称，sandbox 只开放必要能力；
- [ ] 不声称前端可以绕过 frame denial 或同源策略；
- [ ] 图像地图具有普通链接替代；
- [ ] SVG 与 Canvas 的选择依据是数据和交互需求；
- [ ] Canvas 数据存在可读取的文字或表格版本。
