# 第七章：无障碍、SEO 与质量

> 让键盘用户、辅助技术、搜索工具和普通视觉读者从同一份真实内容中获得一致的信息和操作路径。

## 本章任务

邻里集市页面已经可以交互，但功能完成不代表质量完成。本章从三种视角复查：

1. 人能否通过地标、标题、名称、描述和键盘完成任务；
2. 动态结果、错误、焦点和媒体替代是否在变化后仍可理解；
3. 元信息、HTTP 状态、链接和结构化数据是否与可见内容一致。

无障碍不等于“补 ARIA”，SEO 也不等于“堆关键词”。两者共同依赖真实语义、可达流程、稳定状态和诚实内容。

## 学习成果

完成本章后，你将拥有：

- 一份可访问树、地标、标题和名称检查记录；
- 一条完全使用键盘完成查询、收藏和表单恢复的路径；
- 一套动态状态、错误汇总、焦点恢复和媒体替代案例；
- 一个元信息、canonical、robots、HTTP 状态和结构化数据对照页；
- 一份明确区分自动扫描、人工键盘、读屏和跨浏览器验证范围的质量报告。

## 本章知识地图

### 名称和键盘

- 原生角色、地标和标题导航；
- 可访问名称来源及覆盖关系；
- 描述、状态与可见标签一致性；
- 原生键盘激活和焦点顺序；
- `:focus-visible`、skip link、片段目标；
- tabindex 和 ARIA 的使用边界。

### 动态质量

- status、alert、live region 和 aria-busy；
- 表单错误汇总与首个无效控件；
- dialog 关闭和动态列表焦点恢复；
- 图片、字幕、音频描述和图表替代；
- 放大、触控目标、颜色和减少动效；
- 快速更新时通知可能合并的限制。

### 可发现性

- title、description 与正文；
- canonical 和 URL 规范化边界；
- robots meta、robots.txt、抓取和索引；
- sitemap、有效链接与 HTTP 状态；
- 客户端渲染、SSR 与预渲染边界；
- Microdata、JSON-LD 与真实可见内容；
- 虚构评论、库存和评分的风险。

详细落点见 [HTML 教学覆盖矩阵](HTML-COVERAGE.md) 的 A11Y 与 SEO 组。

## 章级综合案例：可搜索商品页

### 个人目录

```text
market-learning/
└── practice/
    └── html-chapter-07/
        ├── index.html
        └── quality-report.md
```

### 关键路径

只用键盘完成：

1. 使用跳过导航进入主要内容；
2. 定位搜索地标和有标签的查询框；
3. 提交查询并获知结果数量；
4. 浏览商品标题、价格、状态和媒体替代；
5. 收藏具体商品并获知内存状态；
6. 打开发布预览，触发错误；
7. 从错误汇总回到首个无效字段；
8. 修正后生成预览；
9. 打开并关闭预约 dialog；
10. 返回仍存在且可操作的触发入口。

### 页面与搜索信息

- 根语言、viewport、具体 title 和 description；
- 一个与实际首选 URL 一致的 canonical；
- 教学环境使用 noindex，并解释它不是权限；
- 商品不存在时由真实服务器返回 404，不用成功状态伪装错误页；
- JSON-LD 只描述页面可见的教学商品；
- 价格从整数分转换到结构化数据要求的货币字符串；
- 不提供虚构评分、库存、成交或认证；
- 客户端动态列表的抓取边界被明确记录。

## 章级故障演练

1. `aria-label` 与按钮可见文字冲突；
2. `div role="button"` 没有完整键盘行为；
3. 多个 navigation 地标没有可区分名称；
4. 使用正数 tabindex 重排焦点；
5. 删除焦点轮廓而没有替代样式；
6. 高频输入每次都触发 alert；
7. 提交失败只显示红边，不提供文字和焦点恢复；
8. 图片/Canvas 只有视觉信息；
9. 状态只用颜色表达；
10. canonical 指向不同商品；
11. noindex 被误当作访问控制；
12. 不存在商品仍返回 200；
13. JSON-LD 添加页面没有的五星评价。

每次记录自动工具能发现什么、人工检查还必须做什么。

## 本章验收

### 无障碍

- [ ] 原生控件优先于重新实现角色；
- [ ] 每个交互控件有准确且与可见文字一致的名称；
- [ ] 地标和标题可以定位页面区域；
- [ ] 键盘顺序与 DOM/视觉任务顺序一致；
- [ ] 焦点始终可见，不使用正数 tabindex 修补布局；
- [ ] 动态消息保留可见文本；
- [ ] 错误可理解、可定位、可修复；
- [ ] 媒体和图表存在等价信息；
- [ ] 颜色、位置或运动不是唯一信息渠道。

### SEO 与一致性

- [ ] title、description 和正文主题一致；
- [ ] canonical 不承担跳转或权限；
- [ ] robots 指令与教学环境目的匹配；
- [ ] 有效链接和 HTTP 状态真实；
- [ ] 抓取与索引没有混为一谈；
- [ ] JSON-LD 语法有效且与可见内容一致；
- [ ] 不制造评论、库存、价格或身份事实；
- [ ] 不承诺排名或富结果。

### 验证范围

- [ ] 自动检查结果没有被描述成完整合规；
- [ ] Chromium 键盘路径已执行；
- [ ] 至少记录一个目标读屏组合的结果或明确未测；
- [ ] Safari、Firefox、移动读屏未测时明确列出；
- [ ] 快速 live region 更新的辅助技术差异已说明。
