# HTML 教学覆盖矩阵

本矩阵用于证明每个知识组不仅在索引中出现，还进入理论、案例、错误诊断、练习和验收。

## 1. 阅读方式

表格中的“是”表示对应详细教程已经落实该维度。全部主要教程均使用可点击链接；验收时应从每一行进入正文，抽查理论、案例、诊断、练习和验收证据，不能只凭文件存在判断完成。

| 标记 | 含义 |
| --- | --- |
| 理论 | 解释目的、语法、内容模型、默认行为或 DOM 映射 |
| 最小案例 | 存在可观察的正确用法 |
| 项目案例 | 进入邻里集市连续项目 |
| 错误诊断 | 有反例、证据、修复和复验 |
| 练习 | 学习者在新输入上独立完成 |
| 验收 | 有可观察的通过条件 |
