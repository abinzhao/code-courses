# 06 现代前端工程化

## 阶段任务

把 React、Vue 和共享能力组织成可维护的 pnpm Monorepo，建立类型检查、Lint、格式化、测试、构建、CI、依赖安全和发布回滚门禁。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W33–W34 | Workspace、依赖边界、共享类型、ESLint Flat Config 和 TypeScript 多项目 | NoteFlow 多包仓库与质量基线 |
| W35–W37 | 设计令牌、组件工作台、测试体系、Bundle、Core Web Vitals 和 CI | 可持续交付的前端工程 |

## 阶段成果

- 依赖边界和共享包职责清晰。
- 从干净目录完成安装、类型检查、Lint、测试和构建。
- 具备接口 Mock、组件测试、E2E 和视觉回归入口。
- 能解释缓存、制品、依赖安全和回滚策略。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第七阶段现代前端工程化)。
