# 08 全栈交付

## 阶段任务

把公共内容侧、React/Vue 管理后台和后端服务连接起来，再用缓存、队列、文件、E2E、Docker、CI 和基础监控完成可重复交付。

## 周次范围

| 周次 | 主题 | 交付方向 |
| --- | --- | --- |
| W44 | Next.js App Router、Server Components、Metadata、SSR 和缓存 | 公共内容侧接入真实 API |
| W45 | Redis 缓存、失效策略、BullMQ、重试、幂等和死信 | 通知与统计异步任务 |
| W46 | 文件上传、对象存储、内容安全、Nest E2E 和 Playwright | 全链路回归测试 |
| W47 | Docker Compose、多阶段构建、Nginx、CI、健康检查和部署 | 可重复部署 |
| W48 | 性能、安全、可观测性、故障演练和答辩 | NoteFlow 1.0 |

## 阶段成果

- 公共内容页具备 SSR、SEO 和可验证缓存行为。
- 异步任务具备唯一键、重试、幂等和失败记录。
- 从干净环境可以启动完整系统并运行 E2E。
- 能查看日志、定位模拟故障、执行回滚并解释恢复证据。

入口与阶段里程碑见[学习路径](../00-course-map/01-learning-path.md#第九阶段全栈集成部署与毕业项目)。
