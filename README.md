# Code Courses · 全栈工程师成长手册

中文任务驱动教材，从第一张网页走到独立交付，再进入 AI Agent、小程序和浏览器扩展开发。
持续项目为邻里集市，包含理论、完整示例、错误实验、练习答案与阶段验收。

从[课程总目录](web-fullstack-course/README.md)开始，按[学习路线](web-fullstack-course/00-guide/learning-path.md)
选择进度。已有 Web 全栈基础的读者可直接进入：

- [本地优先 AI Agent 开发](web-fullstack-course/10-ai-agent/README.md)
- [小程序开发](web-fullstack-course/11-mini-program/README.md)
- [浏览器扩展开发](web-fullstack-course/12-browser-extension/README.md)

教材仅保存 Markdown；应用代码在正文中提供，由学习者在个人工作区创建。
实际检查结果和未验证的平台范围见[交付与验证说明](web-fullstack-course/VALIDATION.md)。
