# Code Courses · 开发者编程实战课程集

> 一套持续更新的**系统化、项目驱动**编程实战课程仓库：每门课程一个独立子目录，从零基础到能独立交付真实项目。

本仓库不堆零散教程，而是按工程师成长路径组织成完整培养体系。每门课都以一个持续演进的主线项目贯穿，所有知识点都必须落到**可运行代码、可评审提交、可复盘文档**上——"看过"不等于"学会"，"能演示"才是完成标准。

## 如何学习

**第一步：选课程。** 从上方课程目录进入对应子目录，先读该课程的 README、课程总纲与教学计划，了解培养目标、阶段路径与每周节奏。

**第二步：按单元推进。** 每个知识单元采用统一的六段闭环结构：

1. **目标** —— 学完应能做出什么（行为化、可观察）
2. **技术栈** —— 本单元用到的工具与稳定版基线
3. **详细的理论知识讲解和示例伪代码** —— 先理解机制，再看示例
4. **课后题** —— 检验概念理解，含大量场景分析题
5. **实践练习题** —— 动手编码，递进式训练
6. **阶段验收作业** —— 用可运行成果和评分表证明真正掌握

**第三步：做项目。** 围绕主线项目把知识点串成完整系统，并以 Git 分支、提交评审、阶段里程碑的方式推进，模拟真实企业协作流程。

## 设计原则

- **机制优先于 API**：先讲清底层原理，再使用框架封装。
- **项目驱动**：每个知识点都有代码落地，每个阶段都有可演示作品。
- **工程化与质量内建**：Git、Lint、类型检查、自动化测试、CI 门禁贯穿全程。
- **安全默认内置**：密钥只走环境变量，最小权限、输入校验、限流与安全头从第一个真实项目开始。
- **版本与时俱进**：统一使用当前 LTS / 稳定版本，不以被主流新项目放弃的旧技术作为主线。
- **证据化学习**：完成由测试结果、运行演示和验收标准定义，而非自我感觉。
