### Task 2: 写入理论知识与机制伪代码

**Files:**
- Modify: `前端全栈工程师培养课程/00-common/01-计算机如何运行Web程序.md`

- [x] **Step 1: 按认知顺序写入七节理论**

使用以下三级标题：

```markdown
### 1. 计算机资源模型
### 2. 从源代码到运行中的进程
### 3. 进程的生命周期
### 4. 栈、堆与内存占用
### 5. CPU 密集型与 I/O 密集型任务
### 6. 浏览器程序与 Node.js 程序
### 7. 用系统证据观察程序
```

每节必须包含通俗定义、Web 开发关系、具体例子和常见误解。概念边界如下：

- CPU 负责执行指令，不负责永久保存数据。
- 内存保存运行时数据，进程退出后不能作为持久化存储。
- 磁盘提供持久化存储，但访问通常慢于内存。
- 网络是一类 I/O，等待网络不等于 CPU 一直计算。
- 源代码不是进程，Node.js 不是操作系统。
- 进程是操作系统管理的运行实例，PID 是当前系统中的标识。
- 栈与堆只讲概念模型，不展开 V8 垃圾回收算法。
- 浏览器运行前端代码，Node.js 可在本机或服务器运行后端代码。

- [x] **Step 2: 写入程序生命周期伪代码**

使用以下机制伪代码：

```text
接收启动命令
请求操作系统创建进程
操作系统分配 PID、内存和其他基础资源
Node.js 运行时加载入口模块
执行当前可以立即执行的代码

如果任务需要文件、网络或定时器:
    发起 I/O 请求
    在等待期间让出执行机会
    I/O 完成后处理结果

如果发生未处理错误:
    记录错误
    返回非零退出码
否则:
    完成任务
    返回零退出码

操作系统回收进程资源
```

- [x] **Step 3: 写入观察命令及预期证据**

必须解释而不是只罗列以下命令：

```bash
node app.js
ps -p <PID> -o pid,ppid,state,%cpu,%mem,command
lsof -nP -iTCP:<PORT> -sTCP:LISTEN

echo $?
```

其中 `<PID>` 和 `<PORT>` 明确标注为学员根据实际结果替换的占位参数，不得填入真实个人数据。
