# L3 阶段考核：可持续交付工程

评分依据：[统一评分标准](./评分标准.md)。

## 任务

完成 [Atlas L3 里程碑](../projects/atlas/milestones/L3.md)，让新成员和 CI 都能稳定复现项目。

必须覆盖：

- pnpm workspace
- 共享配置与 UI 包
- ESLint、Prettier、提交前检查
- 单元、组件、E2E 测试
- 构建体积预算
- Node.js 22/24 CI
- PR 预览与生产环境保护

## 验证

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

必须故意制造并观察：

- Lint 失败
- 类型失败
- 测试失败
- 构建预算失败
- E2E 失败 Trace

## 强制门槛

- 不能依赖本机全局工具
- CI 失败不能继续部署
- 测试不得只追求覆盖率数字
- 锁文件与 package.json 一致
- 预览和生产 Secret 隔离

## 口头检查

1. 解释构建、测试和部署产物。
2. 说明缓存 key 与失效条件。
3. 展示一次 CI 失败的根因定位。
