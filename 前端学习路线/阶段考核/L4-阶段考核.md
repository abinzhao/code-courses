# L4 阶段考核：全栈知识协作平台

评分依据：[统一评分标准](./评分标准.md)。

## 任务

完成 [Atlas L4 里程碑](../projects/atlas/milestones/L4.md) 的认证、文章、评论、审核与部署闭环。

必须覆盖：

- Next.js 16 App Router
- Server Components、Server Functions、Proxy、Route Handlers
- PostgreSQL 18 与 Prisma
- 服务端校验、认证、授权
- 事务、索引、幂等、限流
- 结构化日志、Trace、健康检查
- 容器、迁移、备份、恢复、回滚
- HTTP 体积/超时、文件与子进程边界、事件循环延迟
- 游标分页、API 旧消费者、SSE 或 WebSocket 断线恢复
- revision 并发冲突、缓存失效、可重试任务与重复消费
- [CLI 专项](./专项考核.md#b-npm-包与-cli)：标准流、退出码、dry-run 与拒绝覆盖

## 验证

```bash
pnpm typecheck
pnpm test
pnpm build
docker compose config
```

集成验证：

- 空库执行全部迁移
- 重复发布只产生一次写入
- 普通用户无法审核
- 关闭期间停止接收新流量
- 从备份恢复并跑关键 E2E
- 慢客户端、任务重复投递、分页期间插入、CLI 损坏输入与输出冲突

## 强制门槛

- 服务端不信任客户端角色与资源 ID
- 密码不以明文或快速哈希存储
- 错误响应不暴露堆栈和内部连接信息
- 数据库变更可回滚或有前向修复方案
- 恢复演练有实际数据校验

## 口头检查

1. 画出请求、认证、授权、事务的数据流。
2. 解释一个索引的收益和写入成本。
3. 说明 RPO、RTO 和实际演练结果。
