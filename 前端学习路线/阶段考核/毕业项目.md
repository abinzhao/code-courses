# 毕业项目：Atlas 多入口知识平台

## 目标

独立完成需求、设计、实现、测试、部署与维护闭环。作品覆盖 Web 前端、Node.js 后端、数据库、CLI、npm SDK、安全与扩展入口；跨端与 AI 按专项验收，不以技术名单代替运行结果。

前置：[L0-L5 考核](./README.md)与[专项考核](./专项考核.md)。评分按[统一标准](./评分标准.md)，全部强制门槛通过后总分至少 80。

## 业务范围

1. 公开阅读：列表、筛选、详情、分享、收藏与阅读进度。
2. 作者：登录、草稿、附件、版本冲突、提交审核。
3. 审核员：审核、发布、拒绝原因与审计。
4. 多入口：MV3 主动采集、小程序阅读、移动/桌面离线工作区。
5. 工具：CLI 检查与导出、npm SDK 独立消费者。
6. 可选真实模型：带引用的受控问答；无预算时实现完整 mock adapter 和评测，不宣称模型质量已验证。

## 交付顺序

| 切片 | 完成结果 | 失败验收 |
|---|---|---|
| 阅读 | Web + API + 数据库 | 无数据、接口失败、权限过滤 |
| 编辑 | 草稿、上传、revision | 422、409、重复提交、取消 |
| 审核 | 角色与状态机 | 跳步骤、越权、撤销 |
| 工具 | SDK tarball + CLI | 缺文件、非法参数、覆盖冲突 |
| 扩展 | 主动采集、历史、导出 | 受限页、消息拒绝、worker 重启 |
| 多端 | 小程序 + 一个实际端 | 弱网、权限拒绝、会话过期 |
| 可靠性 | 部署、监控、恢复 | 关闭、告警、隔离恢复、回滚 |
| 安全/AI | 威胁与回归、受限检索 | 注入、无权限资料、工具失败 |

## 必交设计

- 用户角色、资源归属与权限矩阵。
- 数据 ER 图、不变量、索引、迁移和备份恢复。
- API schema、错误码、分页、幂等、revision 与旧消费者规则。
- 浏览器、后端、扩展、跨端和模型之间的数据流与信任边界。
- 3 篇 ADR、1 篇 RFC：写出备选方案、成本、后果与回滚。

## 必交验证

- 类型、Lint、核心测试、构建和真实 E2E 关键旅程。
- SDK tarball 独立安装及 CLI 实际进程测试。
- 本地安全靶场报告与自己实现的权限/输入回归。
- 浏览器窄屏、键盘、bfcache、存储与扩展生命周期证据。
- 数据库空库迁移、并发冲突和隔离恢复后的数据核对。
- 相同设备/网络条件的性能预算与测量。
- 日志、Trace、RUM、SLO、告警及一次事故 Runbook 演练。

部署、商店发布和真实模型调用按自己可用资源及授权执行。未具备条件时可以完成配置、代码和本地演练，但对应远端/设备完成项必须保持“未验证”，不能计入已通过。

## 答辩

现场随机改变一个条件：旧 API 客户端、被撤销身份、数据库慢查询、重复 mutation、扩展 worker 停止或模型流中断。学员应能复现、定位、最小修复并回归，而不是只能演示顺利路径。

最终说明系统当前三个主要限制、原因和下一步验证方式。课程完成意味着能交付与判断，不意味着所有专业方向都已掌握。
