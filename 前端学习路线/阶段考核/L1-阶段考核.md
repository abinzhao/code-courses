# L1 阶段考核：模块化知识工作台

评分依据：[统一评分标准](./评分标准.md)。

## 任务

基于 [Atlas L1 里程碑](../projects/atlas/milestones/L1.md)，把 L0 页面升级为严格 TypeScript 模块化应用。

必须覆盖：

- 文章、筛选、请求、存储类型
- DOM 事件委托
- 搜索防抖与请求取消
- HTTP/协议/业务错误分类
- 本地存储 schema 与迁移
- Worker 索引任务
- 正常、边界、异常测试
- npm scripts、SemVer 与锁文件失配；UTF-8、非法日期与正则边界
- [浏览器数据专项](./专项考核.md#a-浏览器与数据)：来源校验、IndexedDB 迁移与导航恢复

## 验证

```bash
pnpm typecheck
pnpm test
pnpm build
```

故障注入：

- 旧搜索请求晚返回
- localStorage 非法 JSON
- API 返回 HTML 而非 JSON
- Worker 抛出异常
- 锁文件与 package.json 不一致、截断 UTF-8 和无效时间输入

## 强制门槛

- 严格类型检查无错误
- 不使用 `any` 绕过核心数据模型
- 旧请求不能覆盖新结果
- 存储坏数据不会让页面永久白屏
- 核心模块有自动测试

## 口头检查

1. 解释事件循环、Promise 和渲染机会。
2. 说明数组、Map、Set 的选型。
3. 说明一个错误如何跨模块传播和呈现。
