# L5 阶段考核：生产级 Atlas

评分依据：[统一评分标准](./评分标准.md)。

## 任务

完成 [Atlas L5 里程碑](../projects/atlas/milestones/L5.md)，用证据管理性能、安全、可靠性和演进。

必须覆盖：

- Web Vitals 与资源预算
- 威胁模型、安全回归与供应链门禁
- Error、Log、Metric、Trace、RUM
- SLI、SLO、错误预算和燃烧率告警
- Design Tokens、Storybook、可访问性
- 国际化、RTL、PWA 更新和离线冲突
- 跨端 MVP
- ADR、RFC 和技术债治理
- [安全专项](./专项考核.md#c-安全与-web-渗透测试)：本地靶场漏洞/修复版同请求复测
- [扩展专项](./专项考核.md#d-浏览器扩展)：MV3 权限、消息校验和 worker/存储恢复
- [跨端与 AI 专项](./专项考核.md#e-跨端与-ai)：真实端权限/离线和受限检索/工具协议

## 验证

- 相同条件下的性能前后对比
- 安全门禁故意失败
- 告警关联 release 与 Trace
- 键盘、屏幕阅读器和 RTL 回归
- Service Worker 更新与恢复
- SEV-2 事故演练
- 同一 XSS/越权/CSRF 请求修复前后比较，以及扩展 action/受限页面/重启

## 强制门槛

- 性能数据包含设备、网络、版本和样本条件
- 威胁模型覆盖所有信任边界
- 告警有 Runbook 且可行动
- 自动可访问性扫描之外有人工验证
- 架构文档包含备选方案、后果和回滚

## 答辩

1. 用数据说明一项优化为何有效。
2. 用威胁模型解释一项安全控制。
3. 用错误预算说明是否继续发布。
4. 用 RFC 说明一个跨模块决策。
5. 明确系统当前三个最大剩余风险。
