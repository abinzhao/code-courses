# L0 阶段考核：静态知识主页

评分依据：[统一评分标准](./评分标准.md)。

## 任务

基于 [Atlas L0 里程碑](../projects/atlas/milestones/L0.md)，交付首页、文章列表和文章详情。

必须覆盖：

- 320px、768px、1440px
- 语义化 landmark 与标题层级
- 搜索、标签筛选、目录跳转
- 键盘操作与清晰焦点
- loading、empty、error
- 深色模式与减少动画偏好
- 图片尺寸和响应式资源

## 验证

```bash
cd 前端学习路线
npm run atlas:test
npm run validate
```

浏览器证据：

- Network：状态码、MIME、缓存
- Performance：一次交互录制
- Accessibility Tree：导航、搜索和按钮名称
- 200% 文本缩放

## 强制门槛

- 320px 无横向滚动
- 不使用 `<div>` 模拟按钮或链接
- 键盘可完成搜索、筛选和导航
- Console 无未处理异常
- 页面不依赖 `file://`

## 口头检查

1. 解释一个请求到页面绘制的主链路。
2. 说明一次 CSS 冲突如何由层叠规则解决。
3. 展示一个故障的证据链。
