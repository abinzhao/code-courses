# L2 阶段考核：组件化知识平台

评分依据：[统一评分标准](./评分标准.md)。

## 任务

完成 [Atlas L2 里程碑](../projects/atlas/milestones/L2.md) 的 React 主应用和 Vue 迁移页面。

必须覆盖：

- 组件 API 与组合边界
- URL、本地、全局、服务端状态归属
- 嵌套路由、动态参数、404、未授权
- 表单、Dialog、Tabs
- loading、empty、error、disabled
- 数据缓存、重试和失效
- 组件行为测试

## 验证

```bash
pnpm typecheck
pnpm test
pnpm build
```

浏览器验证：

- 直接刷新动态路由
- 后退/前进保持状态
- 慢网与接口失败
- 键盘操作 Dialog/Tabs

## 强制门槛

- 不把所有状态放入全局 store
- 不在 Effect 中复制可推导状态
- 组件测试使用用户可观察行为
- React/Vue 共享数据契约
- 无死按钮和缺失状态

## 口头检查

1. 解释一次渲染和状态更新。
2. 说明服务端状态与客户端状态差异。
3. 解释为何某组件 API 能避免布尔属性膨胀。
