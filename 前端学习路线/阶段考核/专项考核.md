# 全栈专项考核

评分使用[统一评分标准](./评分标准.md)。每项独立计 100 分，80 分通过，并满足强制门槛。主线 L0-L5 考核不能代替这些新增能力的作品。

## A. 浏览器与数据

任务：双来源消息、历史返回恢复、IndexedDB 草稿与版本升级。

验收：

- CORS 允许/拒绝、预检/实际请求能用 Network 与服务端日志区分。
- 非登记窗口无法修改页面状态。
- bfcache 命中或未命中都有实际原因，恢复重新校验身份。
- 旧数据库迁移保留记录，blocked 能恢复，事务中止不部分提交。
- 空间失败可导出，离线同步重复不新增、冲突不静默覆盖。

强制门槛：真实浏览器验证，不以 Node Fetch 代替来源与 Cookie 行为。

## B. npm 包与 CLI

任务：打包 Atlas SDK，并提供数据检查/导出 CLI。

验收：

- tarball 在独立消费者安装，包名导入与声明检查通过。
- 未声明依赖和未导出入口被消费者检查发现。
- 帮助、非法参数、损坏输入、带空格路径和机器输出有真实进程测试。
- 输出已存在时拒绝覆盖；dry-run 不写文件。
- 配置优先级、版本和失败退出码有明确契约。

强制门槛：没有全局工具依赖；打包无秘密；未测试的平台不宣称支持；不要求真实 registry 发布。

## C. 安全与 Web 渗透测试

任务：完成本地靶场四类问题的漏洞版/修复版比较，并将一个 Atlas 同类边界加入回归。

验收：

- XSS 有 DOM marker 的浏览器行为证据。
- 对象越权测试身份明确，拒绝后无内容与副作用。
- 开放重定向不跟随外部地址，仅检查 Location。
- CSRF 记录实际 Cookie/Origin 与状态变化。
- 报告有范围、入口、根因、修复、复测与未覆盖项。
- 故意移除一个控制时门禁失败，恢复后正常路径仍通过。

强制门槛：只测试明确授权目标；不用真实账号/敏感数据；工具告警不直接写成已确认漏洞。

## D. 浏览器扩展

任务：从 MV3 采集器扩展为有历史、导出与清理的本地知识入口。

验收：

- action → popup → worker → isolated world → storage 主路径运行。
- 未登记消息、受限页面和权限拒绝有明确结果。
- popup/worker 关闭后记录仍恢复。
- schema 更新保留旧数据，并发采集不丢记录。
- 数据只在登记范围流转，URL 查询串和文本有隐私规则。
- 运行包只含必要文件，权限与数据用途说明完整。

强制门槛：不能仅靠 chrome Mock；至少一个目标浏览器真实加载；无需商店提交。

## E. 跨端与 AI

任务：完成小程序阅读，以及移动/桌面一个实际端；完成 AI mock 流与受限检索/工具协议。

验收：

- 小程序身份交换在服务端，真机弱网和会话过期保留草稿。
- 移动/桌面端实际安装，权限拒绝、离线、冲突恢复可复现。
- AI 流取消、半帧、错误与完成状态可区分。
- 无权限文档不进入模型上下文，引用指向真实来源。
- 不可信文档无法扩展工具权限，写入工具有明确授权与幂等。
- mock 与真实模型/平台验证分开记录。

强制门槛：没有模型密钥进入公共 bundle；没有任意 shell/SQL/网络工具；没有平台账号或设备时标记未完成实测。
