# 阶段考核

| 阶段 | 考核 |
|---|---|
| L0 | [静态知识主页](./L0-阶段考核.md) |
| L1 | [模块化知识工作台](./L1-阶段考核.md) |
| L2 | [组件化知识平台](./L2-阶段考核.md) |
| L3 | [可持续交付工程](./L3-阶段考核.md) |
| L4 | [全栈知识协作平台](./L4-阶段考核.md) |
| L5 | [生产级 Atlas](./L5-阶段考核.md) |

所有阶段使用[统一评分标准](./评分标准.md)：100 分制，80 分通过，同时满足强制门槛。

考核不是阅读测验。每个结论必须有代码、命令、浏览器记录、日志、Trace 或文档证据，并能在新环境复现。

## 专项与毕业

[专项考核](./专项考核.md)独立验收浏览器数据、npm/CLI、安全渗透测试、浏览器扩展、跨端与 AI。安全报告使用[测试报告模板](./安全测试报告模板.md)，最终完成[Atlas 毕业项目](./毕业项目.md)与现场故障答辩。

阶段文档中的 `pnpm typecheck/test/build` 是学员演进项目需要建立的 scripts。现有 Atlas 起点只提供静态应用及测试，不能把起点通过当作 L2-L5 已实现；未运行的数据库、部署、设备与模型检查须保留未验证状态。
