# Atlas L4：全栈知识协作平台

## 目标

使用 Next.js、Node.js、PostgreSQL 和 Prisma 完成真实认证、数据持久化、API、迁移与部署闭环。

## 必做改动

- 使用 Next.js 16 App Router 和 async Request APIs
- 使用 Server Components、Server Functions、Proxy 和 Route Handlers
- 建立用户、文章、标签、评论、版本和审计表
- 在服务端实施输入校验、认证与资源级授权
- 为写操作定义事务、幂等和并发策略
- 增加限流、健康检查、结构化日志和优雅关闭
- 使用容器启动应用和数据库，并验证全新环境迁移
- HTTP 请求体/超时与文件路径/子进程输入有服务端边界
- 游标与旧消费者契约、实时断线恢复、revision 并发写入
- 缓存失效和有界可重试任务，重复消费不重复副作用
- 数据检查/导出 CLI：机器输出、失败退出码、dry-run 与拒绝覆盖

## 验收

```bash
pnpm typecheck
pnpm test
pnpm build
docker compose config
```

- 未授权请求在服务端被拒绝
- 重复提交不会产生重复写入
- 数据库迁移可从空库重放
- API 错误不泄漏内部堆栈
- 健康检查能区分存活与就绪
- 完成[工具专项](../../../阶段考核/专项考核.md#b-npm-包与-cli)，任务重放与缓存故障有集成证据

- 部署、备份、恢复与回滚演练记录
