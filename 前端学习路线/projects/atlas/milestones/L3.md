# Atlas L3：可持续交付的前端工程

## 目标

把 Atlas 变成可由其他开发者安装、修改、测试和交付的工程，而不是只能在作者机器运行的演示。

## 必做改动

- 使用 pnpm workspace 组织应用、共享类型和 UI 包
- 建立 ESLint、Prettier、提交前检查
- 为纯函数、组件和关键路径建立分层测试
- 配置构建产物分析与体积预算
- CI 使用 Node.js 22/24、锁文件安装和并发取消
- PR 生成预览环境，生产部署需要显式环境保护

## 验收

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

- 新环境按 README 一次成功
- 任一质量门禁失败时 CI 失败
- E2E 失败保留 trace、截图和日志
- 共享包变更触发受影响消费者验证

- 测试策略与覆盖理由
- CI 工作流
