# Atlas L1：类型安全的模块化工作台

## 目标

把 L0 页面升级为模块边界明确、异步行为可验证、数据模型可靠的 TypeScript 应用。

## 必做改动

- 把文章、筛选条件、请求状态建模为 TypeScript 类型
- 开启严格 TypeScript 配置
- 拆分 article、search、storage、render 模块
- 为 Fetch 增加取消、超时、协议校验和错误分类
- 为 localStorage 增加 schema 版本与迁移
- 使用 Worker 处理可测量的索引任务
- 为纯函数、竞态和存储迁移添加测试

## 验收

```bash
pnpm typecheck
pnpm test
pnpm build
```

- 快速搜索时旧请求不能覆盖新结果
- 非法存储数据能自动恢复
- 删除导出或修改类型时编译器能暴露调用点
- Worker 前后有可复现的耗时对比

## 交付

- 类型定义与模块依赖图
- 请求状态机说明
- 存储 schema 与迁移测试
