# Atlas L0：可访问的静态知识主页

## 目标

在不使用框架的前提下，完成结构正确、响应式、可访问、可调试的知识主页。

## 必做改动

- 增加首页、文章列表、文章详情三个可导航视图
- 补齐 loading、empty、error 三种状态
- 使用 Flex/Grid 和容器查询完成 320px、768px、1440px 布局
- 为搜索、筛选、收藏提供键盘路径
- 为图片设置尺寸、替代文本和响应式资源
- 用 DevTools 记录一次请求到渲染的完整链路

## 验收

```bash
npm run verify
```

- 320px 无横向滚动
- 200% 文本缩放后内容不遮挡
- 仅使用键盘可以搜索、筛选和收藏
- Console 无未处理错误
- Network 中 HTML/CSS/JS/API 状态与 MIME 正确

- 可访问性检查记录
- Network 与 Performance 证据
