# Atlas L2：组件化知识平台

## 目标

使用 React 作为主实现，建立组件边界、状态归属、路由和服务端状态模型；用 Vue 重写一个关键页面验证迁移能力。

## 必做改动

- 建立 AppShell、SearchForm、ArticleList、ArticleCard、Tabs、Dialog
- 明确 URL 状态、本地 UI 状态、全局客户端状态和服务端状态
- 使用路由实现列表、详情、工作台与 404
- 覆盖 loading、empty、error、unauthorized、disabled
- 用 TanStack Query 或等价方案管理远程数据
- 实现一个符合 ARIA 键盘模型的复合组件
- 选择文章详情页用 Vue 3 重写

## 验收

```bash
pnpm typecheck
pnpm test
pnpm build
```

- 浏览器刷新后路由状态正确
- 服务端状态不会被复制进无关全局 store
- 组件测试覆盖用户行为而非内部实现
- React 与 Vue 版本共享数据契约，不复制业务规则
