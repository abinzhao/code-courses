## 学习目标

- 能实现流式 UI 的状态、取消、超时与错误恢复。
- 能隔离模型密钥并测量延迟、用量与成本。

## 内容讲解

### 1. 不绑定某个供应商

模型协议、版本、token 计算和价格变化快，先按供应商官方 schema 实现 adapter，再向前端提供自己的稳定事件：

```text
requestId / delta(text) / usage / completed / error
```

HTTP 200 只表示连接建立，后续流仍可能报错。部分文本不等于完整答案，前端需显示 generating、completed、cancelled 与 failed。

### 2. 最小分块读取

以下代码针对 `/api/generate` 返回的纯 UTF-8 文本流，不是通用 SSE 解析器：

```js
const controller = new AbortController();
const response = await fetch('/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ prompt: '概括本地课程' }),
  signal: controller.signal,
});
if (!response.ok || !response.body) throw new Error('生成请求失败');
const reader = response.body.getReader();
const decoder = new TextDecoder();
try {
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    output.textContent += decoder.decode(value, { stream: true });
  }
  output.textContent += decoder.decode();
} finally {
  reader.releaseLock();
}
// “停止生成”按钮应调用 controller.abort()，并保留已生成文本。
```

SSE/NDJSON 需缓冲残缺帧并按协议解析，不能假设一次网络 chunk 就是一条消息。Markdown 输出仍不可信，富文本渲染需要净化与 URL 规则。

### 3. 取消传播

浏览器取消后服务端检测连接断开并取消上游请求，adapter 仍需处理供应商不完全停止或计费延迟。取消不保证立即免费，使用量以实际返回和供应商计费依据为准。

重试要避免重复计费与重复工具副作用。requestId 用于追踪，输入幂等与生成缓存策略需要明确。

### 4. 密钥与隐私

Web 公共客户端不能保存服务端共享模型密钥；服务端使用受控配置。BYOK/本地模式要说明密钥存储、传输与 provider 目标，不能把“本地 UI”写成“数据必不离端”。

默认使用虚构资料与 mock 流完成实验。接真实模型前确认是否发送文档、保留多久、日志如何脱敏。

### 5. 预算与质量

限制 prompt 大小、输出 token、并发、超时与每日额度。记录首 token 延迟、总耗时、成功/取消/错误率和实际用量；token 不是字符数，费用不能按 `.length` 简单估算。

提示词调整需要固定测试样例与版本，不能用一次“看起来更好”证明质量提高。

## 常见问题

**模型返回 JSON 就能信任吗？** 仍需 schema、权限与业务校验。

**AI 答案能直接执行吗？** 不能，工具调用需有限能力与确认，下一课展开。

## 实操作业

基础用 mock 流实现开始/取消；进阶模拟残缺 UTF-8、半帧与流内错误；挑战为一个真实 adapter 写预算与隐私说明。

### 参考答案与验收

取消后 UI 状态明确、上游被通知、部分文本保留；残缺帧不丢字符；密钥不进浏览器 bundle。未调用真实模型时明确仅 mock 协议验证。
