## 内容讲解

### 1. 变量声明：var、let、const

JavaScript 提供三种变量声明方式，它们的差异是面试和日常开发的高频考点。

#### 1.1 核心区别一览

| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | 提升并初始化为 undefined | 提升但进入 TDZ | 提升但进入 TDZ |
| 重复声明 | 允许 | 不允许 | 不允许 |
| 重新赋值 | 允许 | 允许 | 不允许 |
| 声明时必须初始化 | 否 | 否 | 是 |

#### 1.2 作用域（Scope）

```js
// var 属于函数作用域，块（{}）无法限制它
if (true) {
  var a = 1;
}
console.log(a); // 1 —— if 块的 {} 没能关住 var

// let 属于块级作用域，只在定义它的 {} 内有效
if (true) {
  let b = 2;
}
console.log(b); // ReferenceError: b is not defined
```

#### 1.3 变量提升（Hoisting）与暂时性死区（TDZ）

```js
// var 的提升：声明被提升到作用域顶部，初始化为 undefined
console.log(x); // undefined（不报错，这就是提升）
var x = 10;

// let/const 也会提升，但进入"暂时性死区"（Temporal Dead Zone）
console.log(y); // ReferenceError: Cannot access 'y' before initialization
let y = 20;
//    ↑ 从块顶部到 let y = 20 这一行之间就是 TDZ
```

> **避坑提示**：新手最容易犯的错误是以为 `let` 不提升。实际上 `let` 也会提升声明，只是在初始化之前访问会抛错，这个区域叫 TDZ。

#### 1.4 const 的特殊之处

```js
const PI = 3.14;
PI = 3; // TypeError: Assignment to constant variable.

// const 约束的是"绑定"，不是"值本身"
const arr = [1, 2, 3];
arr.push(4); // ✅ 可以！arr 的引用没变
arr = [5, 6]; // ❌ TypeError，不能重新绑定

const obj = { name: 'Alice' };
obj.age = 18;   // ✅ 可以修改属性
obj = {};       // ❌ 不能重新绑定
```

#### 1.5 最佳实践

```js
// 默认用 const，只有确定要重新赋值时才用 let
// 永远不要用 var（除非维护遗留代码）
const MAX_SIZE = 100;      // 常量
let counter = 0;           // 需要重新赋值
// var oldWay = '放弃吧';  // ❌ 不要用
```

### 2. 数据类型

JavaScript 有 7 种原始类型（Primitive）和 1 种引用类型（Object）。

#### 2.1 7 种原始类型

```js
// 1. undefined —— 变量已声明但未赋值
let u;
console.log(u); // undefined

// 2. null —— 表示"空"，需要主动赋值
const n = null;

// 3. boolean —— true 或 false
const isDone = true;

// 4. number —— 64 位双精度浮点数（没有整数/浮点数之分）
const num = 42;
const float = 3.14;
const nan = NaN;          // 不是数字的数字，typeof NaN === 'number'
const infinity = Infinity;// 无穷

// 5. string —— 字符串（不可变）
const str = 'hello';

// 6. symbol —— 唯一标识符
const sym1 = Symbol('id');
const sym2 = Symbol('id');
console.log(sym1 === sym2); // false，即使描述相同

// 7. bigint —— 安全表示任意大的整数
const big = 9007199254740993n; // 尾部加 n
console.log(typeof big); // 'bigint'
```

#### 2.2 引用类型：Object

```js
// Object 是引用类型，存储的是引用的地址
const obj1 = { name: 'Alice' };
const obj2 = obj1;            // obj2 指向同一块内存
obj2.name = 'Bob';
console.log(obj1.name);       // 'Bob' —— obj1 也被改了！

// Object 的子类型
const arr = [1, 2, 3];           // Array
const fn = function() {};        // Function
const now = new Date();          // Date
const re = /abc/;                // RegExp
```

#### 2.3 typeof 的陷阱

```js
typeof undefined;     // 'undefined'  ✅
typeof null;          // 'object'     ❌ 历史遗留 bug
typeof true;          // 'boolean'    ✅
typeof 42;            // 'number'     ✅
typeof 'hello';       // 'string'     ✅
typeof Symbol();      // 'symbol'     ✅
typeof 123n;          // 'bigint'     ✅
typeof function(){};  // 'function'   ✅（实际是 object 的子类型）
typeof [];            // 'object'     ❌ 无法区分数组
typeof {};            // 'object'     ✅
typeof NaN;           // 'number'     ⚠️ NaN 的类型是 number
```

> **避坑提示**：判断 `null` 用 `value === null`，判断数组用 `Array.isArray(arr)`。

### 3. 类型转换

#### 3.1 显式转换

```js
// 转字符串
String(123);        // '123'
(123).toString();   // '123'
String(true);       // 'true'
String(null);       // 'null'
String(undefined);  // 'undefined'

// 转数字
Number('123');      // 123
Number('');         // 0
Number('abc');      // NaN
Number(null);       // 0
Number(undefined);  // NaN
Number(true);       // 1
parseInt('10px');   // 10（提取整数）
parseFloat('3.14m');// 3.14

// 转布尔 —— 记住 6 个 falsy 值
Boolean('');         // false
Boolean(0);          // false
Boolean(-0);         // false
Boolean(NaN);         // false
Boolean(null);       // false
Boolean(undefined);  // false
Boolean([]);         // true（空数组也是 true！）
Boolean({});         // true（空对象也是 true！）
Boolean(' ');        // true（空格字符串）
```

#### 3.2 隐式转换：== vs ===

```js
// === 严格相等：类型和值都相等
0 === '0';      // false，类型不同
0 === 0;        // true

// == 宽松相等：会触发隐式类型转换
0 == '0';       // true，'0' 转成数字 0
0 == [];        // true，[] → '' → 0
0 == false;     // true，false → 0
null == undefined; // true，特殊规则
null === undefined;// false
NaN == NaN;     // false，NaN 不等于任何值，包括自己

// 永远使用 === 和 !==，除非你非常清楚 == 的转换规则
```

#### 3.3 `+` 运算符的特殊行为

```js
// 如果有一边是字符串，+ 执行字符串拼接
1 + '2';        // '12'
'1' + 2;        // '12'
1 + true;       // 2，true → 1
1 + null;       // 1，null → 0
1 + undefined;  // NaN，undefined → NaN

// 对象参与 + 运算时先调用 valueOf 再调用 toString
{} + [];        // 0（{} 被解析为空代码块，+[] = 0）
[] + {};        // '[object Object]'（[]→'' + {}→'[object Object]'）
```

### 4. 运算符

#### 4.1 运算符优先级速查表（高→低）

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 19 | `()` 分组 | — |
| 17 | `++` `--`（后置） | — |
| 16 | `!` `~` `+` `-` `++` `--`（前置）`typeof` `void` `delete` | 右→左 |
| 14 | `**`（幂） | 右→左 |
| 13 | `*` `/` `%` | 左→右 |
| 12 | `+` `-` | 左→右 |
| 7 | `==` `===` `!=` `!==` | 左→右 |
| 6 | `&&` | 左→右 |
| 5 | `\|\|` | 左→右 |
| 4 | `??`（空值合并） | 左→右 |
| 3 | `? :`（三元） | 右→左 |
| 2 | `=` `+=` 等赋值 | 右→左 |

#### 4.2 短路求值（Short-circuit）

```js
// && 短路：左边为 falsy → 直接返回左边，不执行右边
false && console.log('不会打印');
0 && alert('不会弹');

// || 短路：左边为 truthy → 直接返回左边，不执行右边
true || console.log('不会打印');
'hello' || alert('不会弹');

// ?? 空值合并：只在 null/undefined 时取右边
const name1 = null ?? '默认名';      // '默认名'
const name2 = 0 ?? '默认名';         // 0（0 不是 null/undefined）
const name3 = '' || '默认名';        // '默认名'（'' 是 falsy）
const name4 = '' ?? '默认名';        // ''（?? 不会把空字符串当作空）
```

#### 4.3 自增/自减的陷阱

```js
let x = 1;
const y = x++;  // y = 1, x = 2（先赋值再自增）
const z = ++x;  // z = 3, x = 3（先自增再赋值）
```

### 5. 模板字符串和标签模板

#### 5.1 模板字符串

```js
const name = 'Alice';
const age = 25;

// 字符串插值
const msg = `我是 ${name}，今年 ${age} 岁`;

// 多行字符串（不用 + 拼接）
const html = `
  <div>
    <h1>${name}</h1>
  </div>
`;
```

#### 5.2 标签模板（Tagged Template）

```js
// 标签模板允许你用自定义函数处理模板字符串
function highlight(strings, ...values) {
  let result = '';
  strings.forEach((str, i) => {
    result += str;
    if (i < values.length) {
      result += `<strong>${values[i]}</strong>`;
    }
  });
  return result;
}

const author = 'JavaScript';
const res = highlight`学习${author}语法`;
console.log(res); // '学习<strong>JavaScript</strong>语法'

// 实际应用：CSS-in-JS（如 styled-components 就用了标签模板）
```

## 常见问题

### Q1：`let` 有没有提升？

有。`let` 声明的变量在代码执行之前就已经被"注册"到当前块作用域中，但初始化之前处于 TDZ，访问会报 `ReferenceError`。这与 `var` 不同——`var` 提升后会被初始化为 `undefined`。

### Q2：`undefined` 和 `null` 有什么区别？

`undefined` 是"变量已声明但未赋值"，是语言自动设置的；`null` 是"故意为空"，需要手动赋值。语义上：`undefined` = 还没给值，`null` = 主动给了空值。

### Q3：`==` 到底什么时候用到？

几乎不用。仅有少数场景比如 `if (x == null)` 可以同时判断 `null` 和 `undefined`。但这也可以用 `if (x === null || x === undefined)` 替代。建议永远使用 `===`。

### Q4：`NaN` 怎么判断？

```js
Number.isNaN(NaN);     // true
Number.isNaN('abc');   // false（推荐）
// 不要用全局 isNaN()，它会先做类型转换
isNaN('abc');          // true（误导！'abc' → Number('abc') → NaN）
```

### Q5：为什么 `typeof null` 返回 `'object'`？

这是 JavaScript 第一个版本留下的 bug。在 JS 底层，值的类型标记用二进制前三位，对象的标记是 `000`，而 `null` 在内存中表示为全 0，所以被错误地识别为对象。这个 bug 出于兼容性一直保留至今。

### Q6：`const` 声明的对象属性可以修改，那 `const` 还有什么用？

`const` 约束的是变量名和内存地址之间的绑定。对象在堆内存中，变量存的是地址，修改属性不改变地址，所以允许。这让代码意图更清晰——"这个引用不会被重新赋值"。

### Q7：`Symbol` 有什么用？

创建独一无二的属性键，避免命名冲突。常用于框架内部属性、迭代器（`Symbol.iterator`）等：

```js
const id = Symbol('id');
const user = { name: 'Alice', [id]: 123 };
// 普通遍历拿不到 Symbol 属性
Object.keys(user); // ['name']
Object.getOwnPropertySymbols(user); // [Symbol(id)]
```

### Q8：模板字符串和普通字符串拼接哪个性能好？

现代引擎对两者优化得差不多，差异可忽略。优先选择可读性更好的模板字符串。

## 实操作业

### 🟢 基础：变量声明纠错

下面代码有多个问题，找出并修正它们：

```js
var name = 'Alice';
var name = 'Bob';    // 问题1
const PI;
PI = 3.14;           // 问题2
if (true) {
  var age = 25;       // 问题3
}
console.log(age);    // 问题4
let x = 10;
let x = 20;          // 问题5
```

**答案提示**：问题1—重复声明；问题2—const 必须声明时初始化；问题3—var 泄漏到全局；问题4—age 意外可访问；问题5—let 不可重复声明。

### 🟡 进阶：实现一个简单的 SQL 标签模板

```js
// 实现参数化查询描述，不手写 SQL 值转义。
// 参数占位符采用 PostgreSQL 的 $1、$2，值单独交给数据库驱动。
function sql(strings, ...values) {
  // 你的代码
}

const id = 5;
const name = "O'Brien";
const query = sql`SELECT * FROM users WHERE id = ${id} AND name = ${name}`;
console.log(query);
// 期望输出：
// { text: 'SELECT * FROM users WHERE id = $1 AND name = $2',
//   values: [5, "O'Brien"] }
```

参考实现：

```js
function sql(strings, ...values) {
  const text = strings.reduce((result, part, index) =>
    result + (index === 0 ? '' : `$${index}`) + part, '');
  return { text, values };
}
```

真实执行使用驱动的 `query(text, values)`。表名、排序字段等 SQL 结构不能通过此模板传入，需固定语句或允许列表；这个练习不是通用 SQL 构造器。

## 本节小结

- **声明变量**：默认用 `const`，需要重新赋值用 `let`，忘掉 `var`
- **数据类型**：7 种原始类型 + Object，`typeof null === 'object'` 是历史 bug
- **类型判断**：判断 `null` 用 `=== null`，判断数组用 `Array.isArray`，判断 `NaN` 用 `Number.isNaN`
- **相等比较**：永远用 `===`，`==` 只有极少数场景才用
- **模板字符串**：更可读的字符串拼接方式，标签模板是高级玩法
- **运算符优先级**：不确定时加括号，`??` 比 `||` 更精确
