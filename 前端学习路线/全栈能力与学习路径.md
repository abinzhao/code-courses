# 全栈能力与学习路径

## 培养目标

目标是独立交付并维护中型 Web 产品：能从需求建立数据模型与接口契约，完成前端、后端、数据库、测试、部署、监控和恢复；能开发配套 CLI、npm 包与浏览器扩展。能力以作品和失败路径证据验收，不以阅读篇数或学习时长验收。

原生系统编程、内核漏洞研究、模型训练和大型分布式平台属于其他专业方向。本路线提供跨端、AI 应用和分布式协作的应用基础，不能把完成课程等同于精通这些专业。

## 能力闭环

| 能力 | 学习入口 | 必交作品 | 必须证明的失败路径 |
|---|---|---|---|
| 页面与无障碍 | L0 HTML、CSS、响应式与 DevTools | Atlas 页面与键盘检查记录 | 窄屏、内容溢出、错误输入 |
| 浏览器机制 | L0 浏览器原理；L5 浏览器扩展 | 来源隔离、导航恢复、存储实验 | 跨源拒绝、配额失败、后台重启 |
| 语言与异步 | L1 JavaScript、TypeScript | 类型安全搜索、二进制导入模块 | 竞态、取消、乱码、非法日期 |
| npm 与模块 | L1 包管理；L3 npm 包与 SDK | 可安装 tarball 和消费者项目 | 锁文件失配、未导出入口、缺失依赖 |
| 业务前端 | L2 框架与复杂业务界面 | 路由、表单、上传与完整状态 | 重复提交、服务端拒绝、hydration 差异 |
| 质量工程 | L3 构建、测试、Git、CI | 可复现流水线与测试证据 | 故意回归被门禁拦截 |
| Node.js 系统能力 | L4 Node.js 后端基础 | HTTP 服务、文件处理与性能报告 | 超限请求、断开连接、子进程失败 |
| CLI | L4 Node.js CLI | Atlas 数据检查与导出工具 | 非法参数、损坏输入、输出冲突 |
| API 与实时通信 | L4 API 设计与数据层 | 分页、契约版本、SSE 或 WebSocket | 断线、游标失效、旧消费者兼容 |
| 数据库 | L4 数据库基础 | schema、迁移、事务、执行计划 | 并发冲突、约束失败、恢复后对账 |
| 缓存与任务 | L4 生产后端基础 | 缓存策略、可重试任务 | 缓存失效、重复消费、毒消息 |
| 认证与安全 | L4 RBAC；L5 前端安全 | 权限矩阵、威胁模型与安全回归 | 越权、CSRF、XSS、恶意 URL |
| Web 渗透测试 | L5 Web 安全测试 | 本地靶场测试与修复报告 | 同一请求修复前成立、修复后失败 |
| 运维与恢复 | L4 部署；L5 可靠性 | 部署记录、Runbook、隔离恢复 | 进程关闭、数据库故障、回滚 |
| 浏览器扩展 | L5 浏览器扩展开发 | MV3 本地网页采集器 | 受限页面、权限拒绝、worker 被终止 |
| 跨端 | L5 跨端开发 | 小程序、移动端或桌面端作品 | 离线、权限拒绝、会话过期 |
| AI 应用 | L5 AI 应用工程 | 流式问答、引用检索、受限工具调用 | 中断、无检索结果、提示注入 |
| 性能与架构 | L5 性能、观测、治理 | 性能预算、ADR、RFC、事故复盘 | 长任务、告警失效、迁移中途失败 |

## 学习顺序

1. **L0-L1**：先运行原生页面和语言实验。npm 基础在框架安装前完成。
2. **L2-L3**：选 React 或 Vue 为主线；先完成业务状态，再抽取组件和 SDK。另一框架完成迁移练习。
3. **L4**：Node.js 内置模块 → HTTP → 数据库 → 认证授权 → 缓存与任务 → CLI → 部署恢复。Next.js 建立在上述服务端边界之上。
4. **L5**：先做前端安全和威胁建模，再做本地渗透测试；浏览器扩展需要先掌握来源隔离、消息与持久化。
5. **专项与毕业项目**：跨端和 AI 使用同一 Atlas 数据契约；完成[专项考核](./阶段考核/专项考核.md)和[毕业项目](./阶段考核/毕业项目.md)。

目录编号用于导航，先修知识以课程元数据为准。例如浏览器 IndexedDB 实验需要 L1 的 Promise，不必在尚未学习异步时提前完成。

## 练习与参考实现的使用

- 先用课程中的输入和预期结果建立失败证据，再实现正常路径。
- 参考实现用于核对边界；等价实现只要满足契约即可，不要求代码逐字相同。
- 单元测试证明逻辑；浏览器测试证明 DOM、来源策略、布局和扩展运行行为；集成测试证明数据库与进程协作。
- 当前 Atlas 是 L0-L1 的零依赖起点。L2-L5 里程碑是学员需实现的任务，不能把现有起点的测试通过当作全栈系统已经实现。
- 安全测试仅针对自己部署的本地靶场或明确授权的目标。测试记录保存脱敏证据，不采集第三方账号或真实业务数据。

## 学习工作量

每课的建议时间是首次阅读与引导实验预算，不包含大型作业、复习、故障排查和毕业项目。零基础学员按里程碑推进，允许重复实践；不承诺仅靠固定周数达到中级水平。

每周至少留出一次独立实现、一次评审和一次失败复盘。进入下一阶段的条件是对应考核通过，遇到基础断层先回到先修课，而不是增加新框架。
