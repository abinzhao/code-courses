# 小程序开发课程（微信原生方向）

> 状态：🟢 已完成：16 周 32 个单元正文全部产出。

这是一套 **16 周、32 个知识单元**的项目驱动课程，目标是把已有 JavaScript/TypeScript 基础的学员，培养成**能独立完成需求拆解、小程序开发、后端对接、支付交易、性能优化、工程化交付与上架运营的小程序工程师**。课程以微信原生框架为主线打透双线程模型与平台能力，前半程用微信云开发快速跑通全栈链路，后半程对接自建 Node.js 后端理解企业架构，最后以跨端框架（Taro / uni-app）拓展收尾。所有阶段围绕同一条主线项目推进：**「逛吃指南」本地生活小程序**。

## 课程定位与适合人群

本课程培养的不是“会把网页搬进小程序的人”，而是面对一个真实业务需求，能在微信宿主环境的能力边界内，独立完成账号体系、页面与组件、云端数据、登录鉴权、媒体与地图、扫码与支付、订阅消息、分享增长、性能治理、工程化发布与上架运营完整闭环的工程师。

本课程适合以下学员：

- 已掌握 JavaScript（ES2022+）与基础 TypeScript，理解 HTTP、Git，想系统进入小程序赛道的前端开发者；
- 已学过本仓库[前端全栈工程师培养课程](../前端全栈工程师培养课程/)公共基础部分，希望拓展移动端方向的学员；
- 做过简单小程序 Demo，但不理解双线程模型、setData 成本、云函数安全与支付闭环的初学者；
- 只会云开发，想补齐自建后端对接、工程化与自动化测试能力的开发者；
- 希望用一个可上线、可演示、带交易闭环的完整小程序证明工程能力的转岗者。

本课程不适合零基础、未接触过 JavaScript 的学习者（JS 语言基础不单独占用单元，建议先补全栈课程 U08）；也不适合只想拖拽组件、拒绝理解底层机制与平台合规要求的人。课程不以“看过教程”为完成标准，每个阶段只接受**可运行、可演示、可测试、可评审**的成果。

1. 严格按周次顺序学习，每周完成 2 个单元，不跳阶段；云开发与自建后端两条线按课程节奏推进，不提前混学。
2. 每个知识单元采用统一的六段结构：目标、技术栈、理论讲解与示例代码、课后题、实践练习题、阶段验收作业。框架文档不套用该结构。
3. 所有实践练习必须进入 Git 仓库，以 Pull Request 或 Merge Request 形式提交并接受 Code Review。
4. 每周至少完成一次“从报错到根因”的独立排查，并在复盘中记录排查过程。
5. 技术版本统一使用“当前稳定版”表述，不写死小版本；开课时按官方渠道确认具体版本号，遇到版本差异以官方文档、项目实际依赖与基础库为准。

## 五步学习法：目标 → 理论 → 示例 → 练习 → 验收

每个单元都按下面的五步循环完成，禁止只做其中一两步：

1. **目标**：先读单元「目标」，用自己的话复述“学完后应能做出什么行为”，带着行为目标进入学习。
2. **理论**：按理论分节理解机制，每节都回答四个问题——是什么、与小程序开发的关系、一个可运行的示例、一个常见误区。
3. **示例**：先用最小可运行代码或伪代码把机制跑通，确认理解的是原理而不是框架的“魔法”。
4. **练习**：完成课后题和实践练习题，代码必须可运行、提交物齐全。
5. **验收**：对照单元评分表先自评，再提交评审；命中任何“强制不通过条件”一律返工，不接受“差不多”。

## 技术基线总表

课程统一使用当前稳定版本，不写死小版本；开课时按官方渠道确认具体版本号。

| 领域 | 技术基线（当前稳定版） | 用途与说明 |
|---|---|---|
| 语言 | JavaScript（逻辑层 ES2015+）、TypeScript 当前稳定版 | 业务逻辑全程类型化；注意 WXML/WXS 不支持完整 ES 语法 |
| 主线框架 | 微信小程序原生框架 | App/Page/Component 构造器、双线程模型、基础库 |
| 组件框架 | glass-easel（随基础库发布） | 新一代组件内核，Chaining 写法、动态 slot |
| 渲染引擎 | WebView（主线）、Skyline（进阶专题） | WebView 兼容性最稳；Skyline 独立渲染线程、Worklet 动画 |
| 开发工具 | 微信开发者工具当前稳定版 | 模拟器、调试、npm 构建、预览、上传、自动化 |
| 后端（前半程） | 微信云开发 CloudBase | 云数据库、云函数、云存储、云调用与云支付 |
| 后端（后半程） | Node.js 当前 LTS、Express（可选 NestJS） | 对接全栈课程 API，理解企业自建后端架构 |
| 数据库 | 云数据库（文档型）；PostgreSQL（自建后端线） | 云端集合权限与安全规则；关系型建模对照 |
| 登录鉴权 | wx.login、openid/unionid、云函数登录态、JWT | 静默登录、自定义登录态、手机号与头像昵称合规能力 |
| 位置服务 | 微信定位/map 组件、腾讯位置服务 | 定位、POI、逆地址解析、路线规划 |
| 支付 | 微信支付 JSAPI、云开发支付 | 下单、支付、回调验签、退款、对账 |
| 消息触达 | 订阅消息、客服消息 | 一次性/长期订阅、服务通知 |
| 工程化 | npm、ESLint、Prettier、miniprogram-ci | 构建 npm、规范、CI、预览与上传自动化 |
| 组件库 | Vant Weapp 或 TDesign Miniprogram | 企业级 UI 组件复用 |
| 测试 | Jest、miniprogram-simulate、miniprogram-automator | 组件单测、云函数测试、端到端自动化 |
| 跨端拓展（选修） | Taro 当前稳定版、uni-app 当前稳定版 | React 系 / Vue 系跨端入门与选型 |

不作为主线的方式：jQuery/DOM 直接操作（逻辑层无 DOM）、老式 `wx.getUserInfo` 弹窗授权、小程序插件滥用、无后端裸写密钥、以跨端框架替代对原生机制的理解。

## 主线项目：「逛吃指南」本地生活小程序

五个阶段围绕同一个业务主题持续演进，避免“学一个能力写一个一次性 Demo”：

- **业务范围**：微信登录与用户资料；探店笔记的列表、搜索、筛选与详情；图文+定位发布；收藏、点赞与评论；门店地图、POI 与路线导航；扫码领券/核销；活动报名与下单支付；订阅消息提醒；分享与邀请裂变。
- **W4 产出**：四 Tab 静态骨架与详情页，规范的交互反馈与多机型适配。
- **W8 产出**：云开发承接全部数据与文件，登录鉴权与用户体系闭环。
- **W12 产出**：补齐媒体、地图、扫码、支付与订阅消息，形成可商业化交易闭环。
- **W14 产出**：分包与运行时性能达标，分享增长链路与 Skyline 页面落地。
- **W16 产出**：对接自建 Node 后端、工程化与自动化发布、自动化测试，完成上线审核与结业答辩，并以跨端 demo 验证多端迁移能力。
- **最终验收**：小程序为正式已发布版本，代码仓库包含清晰 README、接口与数据结构说明、测试报告、部署与发布记录，学员在答辩中现场演示交易闭环并接受工程能力提问。

## 与全栈课程的衔接

本课程为独立课程，但与[前端全栈工程师培养课程](../前端全栈工程师培养课程/)天然联动：

- 前置：JS/TS、HTTP、Git 等能力直接复用全栈课程公共基础，不重复教学。
- 后端：W15 对接的自建 Node 后端可直接使用全栈课程 W19-W26 的工单/通用 API 成果，理解云开发与自建后端的选型差异。
- 跨端：收尾的 Taro（React 系）、uni-app（Vue 系）与全栈课程的双框架基础互相印证。
