# Web 全栈工程师培养课程

这是一套 **30 周、60 个知识单元**的项目驱动课程，目标是把学员培养成**能独立交付完整 Web 系统的初中级全栈工程师**。课程从操作系统、命令行、网络与语言基础起步，经过 10 周前端（HTML/CSS/浏览器 + React 主线 + Vue 对照）、4 周现代前端工程化、8 周后端，最后用 4 周完成前后端集成、容器化、CI/CD、云部署与结业答辩。五个阶段前后衔接，所有阶段围绕同一条主线项目推进：**团队协作工单系统**。

## 课程定位与适合人群

本课程培养的不是“会写页面的人”，而是面对一个中等复杂业务需求，能独立完成需求拆解、前端界面、后端接口、数据库设计、认证授权、工程化质量、部署上线与文档交付完整闭环的工程师。

本课程适合以下学员：

- 零基础或弱基础，愿意从命令行、网络协议开始系统补课的人；
- 能写简单页面，但不了解浏览器原理、工程化和质量体系的前端初学者；
- 只做过前端，想补齐 Node.js 服务端、数据库、认证授权与部署能力的人；
- 已掌握一个框架，希望同时具备 React 与 Vue 双框架交付能力、拓宽岗位适配面的人；
- 希望用一个完整的、可上线演示的全栈项目证明自己工程能力的转岗者。

本课程不适合只想学页面特效、拒绝命令行与服务端知识、或希望“只看视频不写代码”的学习者。课程不以“看过教程”为完成标准，每个阶段只接受**可运行、可演示、可测试、可评审**的成果。

## 五步学习法：目标 → 理论 → 伪代码 → 练习 → 验收

每个单元都按下面的五步循环完成，禁止只做其中一两步：

1. **目标**：先读单元「目标」，用自己的话复述“学完后应能做出什么行为”，带着行为目标进入学习。
2. **理论**：按理论分节理解机制，每节都回答四个问题——是什么、与 Web 开发的关系、一个可运行的示例、一个常见误区。
3. **伪代码**：先用伪代码或最小可运行代码把机制跑通，确认理解的是原理而不是框架的“魔法”。
4. **练习**：完成 8-10 道课后题和不少于 3 个实践练习题，代码必须可运行、提交物齐全。
5. **验收**：对照单元的 100 分评分表先自评，再提交评审；命中任何“强制不通过条件”一律返工，不接受“差不多”。

## 技术基线总表

| 缓存与队列 | Redis 当前稳定版、BullMQ 当前稳定版 | 缓存、异步任务与定时任务 |
| 认证与密码 | JWT、bcrypt 或 argon2 当前稳定版 | 密码哈希加盐、令牌签发与刷新 |

## 工程化阶段定位说明：为何独立成阶段

「现代前端工程化」占据 W15-W18 共 8 个单元，是课程新增的独立阶段，而不再是夹带在框架课里的零散技巧。独立成阶段的原因：

1. **能力性质不同**：框架教学解决“如何写出界面”，工程化解决“团队如何稳定、可重复、可协作地把界面交付到生产”，两者的思维方式与评价标准不同。
2. **知识体量已成体系**：构建原理（Vite/Rollup/Webpack 存量）、代码规范与提交门禁、多环境配置、Monorepo 工作区、npm 包开发与发布、前端 CI/CD、微前端与模块联邦，构成完整链路，需要专门的学习与练习顺序。
3. **岗位要求独立可考核**：企业招聘中“构建优化、规范治理、流水线搭建”是独立考察项，必须有独立的阶段产出与里程碑（W18）作为证据，而不能只靠“项目里配过一次”。
4. **承上启下的位置**：放在前端之后、后端之前，学员带着真实 React/Vue 项目进入工程化改造，再带着工程化能力进入后端与全栈集成，避免学完所有内容才回头补工具链。

W18 里程碑要求学员交付完整工程化能力：Vite/构建、规范、多环境、Monorepo、包发布、前端 CI。

## 双框架说明：React 主线，Vue 对照

课程采用 **React 主线、Vue 对照**的双框架设计，而不是二选一：

- **React 为主线（W9-W12，8 单元）**：学员用 React 完成工单系统前端原型的完整链路——组件模型、Hooks 与状态、路由、服务端状态、复杂表单、错误边界与性能、组件测试、E2E 与质量门禁。主线练习、阶段产出与后续全栈联调均以 React 项目为基准。
- **Vue 为对照（W13-W14，4 单元）**：在学员已建立完整前端能力后，用当前稳定版 Vue 做对照学习：SFC 与组合式 API、Proxy 响应式原理、Vue Router 与 Pinia、表单请求测试与生态集成。重点不是“再背一套 API”，而是通过同一业务在两种框架下的实现，理解组件模型、响应式机制、状态管理与副作用处理的共性与差异。
- **双框架目标**：结业时学员既能用 React 独立交付，也能快速接手 Vue 项目；能讲清两个框架在响应式原理、状态组织与生态配套上的权衡，具备岗位所需的框架迁移与适配能力。

## 结业项目：团队协作工单系统

五个阶段围绕同一个业务主题持续演进，避免“学一门技术写一个一次性 Demo”：

- **业务范围**：用户注册登录与团队成员管理；项目与看板；工单的创建、分配、状态流转、优先级与标签；评论与活动记录；筛选、搜索、分页与统计看板；基于异步队列的通知。
- **前端阶段产出（W14）**：用 React 完成工单系统界面与交互全链路及测试门禁，并用 Vue 对照实现核心模块；服务端数据先用 Mock 承接。
- **工程化阶段产出（W18）**：把前端项目纳入完整工程化体系：Vite 构建、ESLint/Prettier 与提交门禁、多环境配置、Monorepo 工作区、可发布包与前端 CI。
- **后端阶段产出（W26）**：用 Express、PostgreSQL、Prisma 实现资源模型、认证授权、校验安全与测试，补齐 Redis 缓存与异步通知。
- **全栈阶段完成集成交付（W30）**：用 OpenAPI 固化契约并同步类型，前后端联调；Docker Compose 一键启动多服务；GitHub Actions 跑测试、构建与镜像；部署到云主机，经 Nginx 反向代理并启用 HTTPS；接入结构化日志、健康检查与错误追踪。
- **最终验收**：系统可通过公网地址访问，代码仓库包含清晰 README、契约文档、测试报告与部署记录，学员在答辩中现场演示并接受工程能力提问，按全栈能力矩阵逐项对证。
